### 阶段6：分批卖出（阶梯止盈 + 盘中量价背离，✅ 完成，`docs/reports/phase6_ladder_tp.md`）
- 背景：隆平高科实战复盘发现"冲高途中无法预知顶"——09:37 峰值 9.84 时不知是顶，10:19 回落 2%
  触发出售于 9.40（事后看已是当日最优卖点）；单一"回撤全清"无法兼顾"吃趋势"与"锁定利润"
- **① 阶梯止盈（分批）**：`LADDER_TP_STEPS` 阶梯分批——+4% 卖 1/3、+6% 再卖 1/3，剩余 1/3
  由全清止盈(+8%)/回撤/移动止损/超时接管。**不与其他退出规则互斥**（阶梯是附加分支）。
  实现 `trader.py::_ladder_tp_sell` + `engine.py`（同一台阶表零漂移，已兑现记 `ladder_sold` 防重）。
- **② 盘中量价背离卖出（秒级/分钟级，主推）**：量价脱离是盘中行为，故用**实时 quote（每5秒）+
  分钟量比**（minute_vol 前5日同时段均量，本地 min5.db 零额外网络）判定，不依赖日K，参考
  [clcc2019/stock-intraday-trading](https://github.com/clcc2019/stock-intraday-trading)、
  [gechengling/chanlun-analysis-pro](https://github.com/gechengling/chanlun-analysis-pro) 分时策略：
  - **放量滞涨**（分钟量比>2× 且 价自当日高点回落≥0.5%）→ 对倒派发，**清仓**
  - **高位缩量上冲**（涨≥5% 但分钟量比<0.7，即无量上涨）→ **卖半仓锁利**（A股缩量新高常续涨，
    不宜全卖，留一半吃趋势）
  实证（全市场 1206 只一年）：**放量滞涨卖出有效**（触发后 3日≈0%<基线0.35%）；**缩量新高反而
  常续涨**（3日+6.23%、胜率62.5%，不可清仓所以只卖半）——纠正常见"无量就卖"误区。
- 回测（冻结快照 82 只本地一年，score，同池同参）：阶梯止盈 vs 现状全清——
  收益 **-9.03% vs -9.80%**、回撤 **-17.41% vs -18.31%**、
  胜率 **52.6% vs 36.3%**（+16.3pp）；产生 100+ 笔分批兑现 → 减损 + 释放持仓周转，全面占优
  （注：冻结快照指取 date≤2026-08-18 的数据回测，避免增量更新污染；上市/震荡市待多窗口复验）
- 开关：`LADDER_TP_ENABLED = True`（**默认常开**，用户配置）；`VOLP_SELL_MIN_ENABLED = False`
  （分钟级量价卖出，默认关，开盘前验证后再开）；日K版 `VOLP_SELL_ENABLED = False`（辅助对比用）。
  `tools/backtest_ladder_tp.py` / `tools/backtest_volprice_sell.py` 可复跑。

## Phase 11：walk_forward 升级（滚动切分 + 网格调参 + degradation，✅ 完成）

### 1. 滚动切分（`app/engine.py::walk_forward`）
- 新参数：`train_days=252` / `test_days=126` / `step_days=126` / `anchored=False`
- `anchored=True`：训练起点固定（区间起点）、终点随折滚动（`起点+train_days+i*step`）
- **folds 兼容**：未显式给滚动参数时，旧式 `folds`（含默认 3）自动换算为等长滚动切分
  （`train=test=step=total//(folds+1)`），旧调用 `walk_forward(..., folds=3)` 不报错、语义等价
- 末折测试段自动收口到 `end`；残余过短（<测试段一半）不再开折

### 2. 训练段网格调参（替代原单参数敏感度扫描）
- `buy_threshold × max_positions` 小网格：`[20,25,30] × [2,3,4]`
- 选优指标沿用 `收益 − 0.5×|回撤|`，要求 `trade_count≥5`
- 无合格候选 → 回退默认 params（不报错）；每折输出 `best_threshold` + `best_params`

### 3. 每折 degradation（衰减率）
- `degradation = 1 − OOS收益/IS收益`；IS≤0 时置 `None`
- 汇总新增 `avg_degradation`；verdict 沿用现有风格（✅ 稳健 / ⚠️ 不稳定）

### 4. 服务透传（`app/server.py::_run_backtest_job`）
- 从 payload 取 `wf_train_days` / `wf_test_days` / `wf_step_days` / `wf_anchored`，缺省用默认值

### 验收
- ✅ 30 只 × 14 个月，`folds=2`（等长滚动）跑通：2 折，各含 `degradation`
  （折1 IS+15.0%/OOS−23.4%→衰减2.55；折2 IS≤0→None）
- ✅ 旧式 `folds=3` 不报错、出 3 折（修复初版"只出 1 折"的换算歧义）
- ✅ 显式滚动参数 + `anchored=True`：训练起点固定终点滚动 3 折、末折收口正常
- ✅ `/api/backtest` mode=walk_forward 链路透传新参数正常；冒烟 8 项 PASS
