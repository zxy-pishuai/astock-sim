# A股模拟盘 4.0 实战体系调研纪要

> 与 A股实战（打板生态/情绪周期/题材轮动/筹码博弈）完全是两套体系。
> 4.0 的核心 = 把"教科书因子库"升级为"实战派体系"。

## 一、情绪周期体系（4.0 第一优先级，当前完全缺失）

### 数据源（已实测可用，纯 urllib）
- 涨停池：`https://push2ex.eastmoney.com/getTopicZTPool?ut=7eea3edcaed734bea9cbfc24409ed989&dpt=wz.ztzt&Pageindex=0&pagesize=200&sort=fbt:asc&date=YYYYMMDD`
- 跌停池：`.../getTopicDTPool?...`（同参数）
- 涨停池字段：`c`代码 `n`名称 `zbc`炸板次数 `hybk`行业 `fbt`首次封板时间 `lbt`最后封板 `fund`封板资金 `zttj.days`连板数
- 历史日期回补可用（20260813 正常，部分早期日期可能为空）

### 情绪指标（实战派核心，参考 limit-up-sniper / vibe-astock / daben-review）
1. **涨停家数 / 跌停家数**（冰点 vs 高潮）
2. **连板高度**：当日最高连板数（空间板）
3. **炸板率**：炸板数 / (封板数+炸板数)
4. **昨日涨停今日溢价**（情绪温度计）：昨涨停股今高开率/收盘表现
5. **晋级率**：首板→2板概率（分层）
6. **梯队断层**：连板梯队是否断裂（如 3板断档）
7. **封板率 / 封板资金**：封单强度

### 情绪-仓位联动（替代现有 REGIMES 上涨占比分级）
- 冰点（涨停<30 家 + 炸板率高）→ 空仓/轻仓
- 发酵 → 打板
- 高潮 → 减仓
- 退潮 → 空仓防守

## 二、龙头质量打分（参考 dragon-quant）
- **带动性**：能否带动板块/大盘
- **抗跌性**：分歧日跌幅小
- **领涨性**：率先涨停/封板时间早
- **资金承接性**：封单量/换手结构
- 实战规则（游资心法）：身位、辨识度、卡位、分歧转一致

## 三、实战因子库（替换/补充教科书因子，接入现有 IC 体系）
- 昨日涨停溢价、连板高度、封板时间、炸板率、封单/流通比、大单净流入

## 四、LLM 决策/复盘层（参考 xuanji / ai-hedge-fund / TradingAgents-astock）
- LLM 只做"复盘/建议/研报"，下单必须过硬风控（现有 risk.py 已是硬风控架构）
- 盘后"分析师辩论团"（bull/bear 多轮辩论）产出次日计划

## 五、实战成本/撮合（已有 v3.8 成交概率，可强化）
- 涨停排队/一字板买不进（已有成交概率模型）
- 影子验证（模拟盘与实盘并行对照）
