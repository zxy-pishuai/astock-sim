# A股资金流/盘口/筹码实战数据源调研报告（模拟盘 4.0 升级用）

> 调研时间：2026-08-16。所有结论基于 web 调研 + **本机活体实测**（6 个关键接口直接请求验证，实测结果已标注）。北向实时披露确已停（2024-08-19 起交易所取消盘中实时披露，仅保留盘后成交总额与持股）；**龙虎榜 / 涨停池 / 资金流接口全部仍存活**（实测拉到 2026-08-14 交易日的实时数据）。
> 技术约束：目标项目为**纯 Python 标准库**模拟盘 → 优先 urllib/http.client 可直连的 HTTP JSON 接口；通达信 TCP 方案需要第三方库（若不能引入依赖，用腾讯/东财 HTTP 五档替代）。

## 一、Level-2 近似数据（逐笔 / 盘口 / 大单）

### 候选 A：通达信 TCP 协议（mootdx / easy_tdx / eltdx）—— 真正的"逐笔 + 五档"
- **实战价值**：五档盘口（bid1-5/ask1-5 价格量）+ **逐笔成交明细**（time/price/vol/主动买卖方向），是免费能达到的"最接近 Level-2"的数据；可自算主动买卖盘比、大单拆分、挂单撤单强度。
- **接口**：TCP 7709 二进制（非 HTTP）。mootdx 库已烂尾（2024 停更）但协议照常，社区活跃替代 `easy_tdx`、`eltdx`（均开源、支持快照/分时/逐笔/K线/集合竞价）。
- **落地难度**：低（`pip install easy_tdx` 即可），但**违反纯标准库约束** → 模拟盘若坚持零依赖，本候选降级为参考。需注意海外 IP 无法连通达信服务器（TCP 7709 国内服务器）。
- 参考：[mootdx](https://github.com/mootdx/mootdx) / [easy_tdx](https://zread.ai/handsomejustin/easy_tdx) / [eltdx](https://github.com/electkismet/eltdx) / [tdx_quant](https://github.com/henrylin99/tdx_quant)

### 候选 B：腾讯财经 qt.gtimg.cn —— 免费五档盘口（**实测可用**）
- **实战价值**：一次性拿全 实时价/PE/PB/市值/换手率/涨跌停价/**买卖五档**/量比，批量查询，不封 IP，是最稳的 Level-2 近似行情底座。
- **接口**（GBK 编码，`~` 分隔）：
  `https://qt.gtimg.cn/q=sh600519,sz000858`（可批量，逗号分隔）
  实测返回字段索引（**实测确认**）：`[1]名称 [3]现价 [4]昨收 [5]今开 [6]成交量(手) [7]外盘 [8]内盘 [9]买一价 [10]买一量 [11]买二价 [12]买二量 … [17]买五量 [18]卖一价 [19]卖一量 … [27]卖五量 [30]时间 [31]涨跌额 [32]涨跌幅 [33]最高 [34]最低 [37]成交额(万) [38]换手率 [39]PE(TTM) [44]流通市值 [45]总市值 [46]PB [47]涨停价 [48]跌停价 [49]量比`
- **落地难度**：极低（urllib GET + GBK decode + split('~')，纯标准库）。注意前缀路由：6/5/9 开头→`sh`，0/3→`sz`，92/8→`bj`；000300 等沪指数需白名单。

### 候选 C：东财 push2（五档 / 分时）—— 免费但**有风控**
- **接口**：
  - 个股快照（含五档字段 f19-f40 区间、最新价 f43、成交额 f48、换手 f168、涨跌幅 f170 等）：`https://push2.eastmoney.com/api/qt/stock/get?secid=1.600519&invt=2&fltt=2&fields=f43,f44,f45,f46,f47,f48,f49,f50,f57,f58,f60,f107,f116,f117,f162,f167,f168,f169,f170,f171`
  - 当日分时：`https://push2his.eastmoney.com/api/qt/stock/trends2/get?secid=1.600519&fields1=f1,f2,f3,f7,f8&fields2=f51,f52,f53,f54,f55,f56,f57,f58&ndays=1`
- **实测**：本机 push2 `stock/get` 与 `clist/get` 间歇性连接被重置（WAF 风控），而 push2ex/fflow 正常 → 印证"东财不同子域/端点独立风控"，**必须串行限流 + UA + Referer**。
- **落地难度**：中（需内置限流与降级，见第六节）。

### 候选 D：新浪历史逐笔成交 transHis.php —— 免费逐笔（**实测存活**）
- **实战价值**：**历史逐笔成交明细**（成交时间/价/量/额/主动买卖性质），可用于回测盘口强度、主力吸筹痕迹、验证当日资金流真实性。
- **接口**：`https://market.finance.sina.com.cn/transHis.php?symbol=sh600519&date=2024-01-15&page=1`（GBK HTML 表格，约 8000 笔/日、80 笔/页需翻页）。实测 HTTP 200（页面标题"历史成交明细/逐笔交易"）。
- **落地难度**：中（HTML 解析 + 翻页，纯标准库可行）；需自行封装容错，因无官方文档、结构可能变动。

> **Level-2 小结**：免费天花板 = 五档 + 逐笔（通达信 TCP 或新浪历史逐笔）+ 分钟资金流；**真十档/千档/盘口撤单还原是付费 Level-2 数据（同花顺/东财/量化厂商）**，免费方案只能"近似"。

## 二、龙虎榜深化（机构买入 / 游资席位 / 三日榜 / 净买入额）

### 东财 datacenter（免费、零鉴权、与项目现有接入同域同风格）—— **核心**
统一端点：`https://datacenter-web.eastmoney.com/api/data/v1/get`，参数 `reportName / columns / filter / pageNumber / pageSize / sortColumns / sortTypes / source=WEB&client=WEB`。

| 需求 | reportName | filter 示例 |
|---|---|---|
| 个股上榜记录（含三日榜原因、净买额、换手率） | `RPT_DAILYBILLBOARD_DETAILSNEW` | `(TRADE_DATE>='2026-07-01')(TRADE_DATE<='2026-07-30')(SECURITY_CODE="002475")`，`sortColumns=TRADE_DATE` |
| 买入席位 TOP5（营业部名/买额/卖额/净额） | `RPT_BILLBOARD_DAILYDETAILSBUY` | `(TRADE_DATE='...')(SECURITY_CODE="...")`，`sortColumns=BUY` |
| 卖出席位 TOP5 | `RPT_BILLBOARD_DAILYDETAILSSELL` | 同上，`sortColumns=SELL` |
| 全市场每日龙虎榜（净买额排名） | `RPT_DAILYBILLBOARD_DETAILSNEW` | 单日 filter + `sortColumns=BILLBOARD_NET_AMT` |

- **机构专用席位**：`OPERATEDEPT_CODE=="0"`（在买卖席位明细中筛选），聚合得机构买入/卖出/净额 —— 对应"机构买入"实战信号。
- **三日榜**：无需单独报表 —— 上榜原因 `EXPLANATION` 字段含"连续三个交易日内…"即三日榜条目；配合 30 日回看窗口做"多次上榜+机构持续买入"聚合。
- **实战策略**：① 机构净买 + 游资接力（机构买+知名游资买入同日上榜）→ 次日溢价统计；② 净买额 TOP 板块性聚集（多只同题材同日上榜）→ 题材强度确认；③ 席位历史胜率/盈亏画像。
- **落地难度**：低（与项目已接的 datacenter 龙虎榜/两融/北向完全同款，只需新增 2 个 reportName + 机构筛选逻辑）。参考完整实现见 [a-stock-data §3.5/§3.9](https://github.com/simonlin1212/a-stock-data/blob/main/SKILL.md)。

### 游资席位数据库
- **免费静态名单**（知名游资↔营业部映射，社区维护，需人工审核更新）：
  - [常见龙虎榜游资席位一览表（东财财富号）](https://caifuhao.eastmoney.com/news/20250209224756905041420)
  - [龙虎榜：各大元老及席位](https://caifuhao.eastmoney.com/news/20251114025804913640970)
  - [各路游资席位（360doc，2023-11 版）](http://www.360doc.com/content/24/0502/06/52230674_1122117303.shtml)、[知名游资前50位所对应的营业部名单](http://www.360doc.com/content/25/0404/14/16303363_1150538303.shtml)、[淘股吧 A股龙虎榜游资席位一览](https://m.tgb.cn/a/1Y24ItWmSB4)
- **席位画像/识别开源方案**：[quantskills/skill-smart-money-profiler](https://github.com/quantskills/skill-smart-money-profiler)（LHB 席位身份识别 + 北向行为 + 多源资金共识/背离）。
- **商业免费档**：[stockapi.com.cn](https://github.com/hjhgogo/stockapi)（免费 API 聚合，含龙虎榜/游资/涨停池等，需注册 key，适合不想自建爬虫的备选）。
- **落地建议**：本地维护 `游资映射表.json`（营业部名 → 游资代号/风格），叠加每日龙虎榜席位明细 → 输出"今日上榜游资/机构"事件流，并滚动统计各席位近 60 日胜率与次日溢价 —— 这是模拟盘最易落地且实战价值最高的龙虎榜深化。

## 三、资金流（主力 / 超大 / 大 / 中 / 小单）

> 澄清：社区流传的"东财 push2 资金流 `format=ffa`"**不是真实参数**；实测可用的免费接口是下面两个 push2 fflow 端点（akshare `stock_individual_fund_flow` 同款）。

### ① 个股分钟级资金流（盘中实时，**实测可用**）
```
https://push2.eastmoney.com/api/qt/stock/fflow/kline/get
  ?secid=1.600519            # 1.沪 / 0.深 / 0.北
  &klt=1                     # 1=分钟级（当日盘中）
  &fields1=f1,f2,f3,f7
  &fields2=f51,f52,f53,f54,f55,f56,f57
```
返回 klines 每行：`时间,主力净额,小单净额,中单净额,大单净额,超大单净额`（单位**元**）。可累计出全天主力净流入曲线 → 判断尾盘/早盘主力动向。

### ② 个股日级 120 日资金流
```
https://push2his.eastmoney.com/api/qt/stock/fflow/daykline/get
  ?secid=1.600519&klt=101&lmt=120
  &fields1=f1,f2,f3,f7
  &fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61,f62,f63,f64,f65
```
同样返回五档净额（日级）。**实战用法**：近 5/20 日主力累计净流入、主力净流入与股价背离（价涨钱出 = 出货嫌疑）、超大单占比拐点。

### ③ 全市场资金流排行（超大/大/中/小单 + 净占比）
```
https://push2.eastmoney.com/api/qt/clist/get
  ?fid=f62&po=1&pz=50&pn=1&np=1&fltt=2&invt=2
  &fs=m:0+t:6+f:!2,m:0+t:13+f:!2,m:0+t:80+f:!2,m:1+t:2+f:!2,m:1+t:23+f:!2,m:0+t:7+f:!2,m:1+t:3+f:!2
  &fields=f2,f3,f12,f14,f62,f184,f66,f69,f72,f75,f78,f81,f84,f87
```
字段：`f62 主力净额 / f184 主力净占比 / f66 超大单净额 / f69 超大净占比 / f72 大单 / f75 大单占比 / f78 中单 / f81 中单占比 / f84 小单 / f87 小单占比`。本机实测该 clist 端点被 push2 WAF 间歇重置（需限流重试）。

### ④ 板块资金流（行业/概念/地域 × 今日/5日/10日）—— 板块轮动核心
```
https://push2.eastmoney.com/api/qt/clist/get
  ?fid=f62&po=1&np=1&fltt=2&invt=2
  &fs=m:90+t:2            # 2=行业 / 3=概念 / 1=地域
  &fields=f12,f14,f3,f62,f184,f66,f72,f78,f84,f204
```
周期字段：今日主力 `f62`、5日 `f164`、10日 `f174`（对应占比 `f184/f165/f175`）；今日四档 `f66/f72/f78/f84`。实现参考 [a-stock-data §3.8](https://github.com/simonlin1212/a-stock-data/blob/main/SKILL.md)（含翻页、字段去重）。

### ⑤ 降级备用（东财被封时）
- 新浪日度资金流：`https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/MoneyFlow.ssl_qsfx_zjlrqs?page=1&num=60&sort=opendate&asc=0&daima=sh600519`（四档日净额，含净占比/换手，零鉴权）。

## 四、涨停板数据（涨停家数 / 连板 / 涨停时间 / 昨日涨停表现）—— **实测可用**

### ① 东财涨停行情中心四池（push2ex，免登录零鉴权，**实测拉到 2026-08-14 数据**）
```
https://push2ex.eastmoney.com/getTopicZTPool?ut=7eea3edcaed734bea9cbfc24409ed989&dpt=wz.ztzt&Pageindex=0&pagesize=10000&sort=fbt:asc&date=20260814
```
四个端点（仅 sort/池子不同）：`getTopicZTPool`（涨停池）、`getTopicZBPool`（炸板池）、`getTopicDTPool`（跌停池）、`getYesterdayZTPool`（昨涨停今表现）。
实测字段（贵州茅台无需，取华西股份）：`lbc` 连板数、`fbt` 首次封板时间（92500→09:25:00）、`lbt` 最后封板时间、`fund` 封板资金(元)、`zbc` 炸板次数、`hybk` 行业、`zttj` 几天几板（{days,ct}）、`zdp` 涨跌幅。**实测 2026-08-14 涨停 63 只，华西股份 3 连板（3天3板）、炸板 7 次、封板资金 4394 万**。

### ② 同花顺涨停揭秘（涨停原因题材 + 封板成功率 + 板型）
```
https://data.10jqka.com.cn/dataapi/limit_up/limit_up_pool
  ?page=1&limit=200&filter=HS,GEM2STAR&order_field=330324&order_type=0&date=20260626
  &field=199112,10,9001,330323,330324,330325,9002,330329,133971,133970,1968584,3475914,9003,9004
```
字段：`reason_type` 涨停原因题材、`limit_up_suc_rate` 封板成功率、`limit_up_type` 板型(换手/一字/T字)、`open_num` 炸板次数、`order_amount` 封单额、`high_days` 几天几板、`first_limit_up_time`（**Unix 秒时间戳**，需转换）。这是"涨停原因归因"的免费独有源。

### ③ 情绪温度计（四池组合本地速算）
- 涨停家数 = len(涨停池)；炸板率 = 炸板/(涨停+炸板)；最高连板、连板梯队 {板数:家数}；
- **晋级率** = 昨涨停今涨幅≥9.8% 家数 / 昨涨停总数（`getYesterdayZTPool` 自算）；
- 东财重点监控池（风险警示名单+生效时间窗，静态 JSON）：`https://mobappconfig.securities.eastmoney.com/emcfg/stock_monitor.json`。
- 完整实现参考 [a-stock-data Layer 8](https://github.com/simonlin1212/a-stock-data/blob/main/SKILL.md)。

## 五、筹码分布 / 获利比例 —— **没有直接免费接口，但可本地复刻**

- **结论（实测）**：东财数据中心并不存在"筹码分布"报表 —— `datacenter / securities api` 的 `RPT_CUSTOM_CYQ` 实测返回 `报表配置不存在`。同花顺/通达信客户端的筹码分布是**客户端本地算法**，不是数据接口。akshare `stock_cyq_em` 的本质是：**拉东财日K（含换手率）→ 本地跑东财网页前端同款 `CYQCalculator` JS 算法**（120 日窗口、150 档价格区间三角分布）。
- **免费实现路径**（纯标准库可做，推荐）：
  1. 日K+换手率：`https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.600519&klt=101&fqt=1&fields1=f1,f2,f3,f4,f5,f6&fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61&beg=20240101&end=20500101`（返回 日期/开/收/高/低/量/额/振幅/涨跌幅/涨跌额/换手率）；
  2. 复刻 CYQ 三角分布算法 → 输出 **获利比例（profit ratio）/ 平均成本 / 90%·70% 成本区间 / 集中度 / 150 档筹码直方图**。
- **开源参考**：[akshare stock_cyq_em 源码](https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_cyq_em.py)（JS 版算法可直接翻译）、[stock-sdk（chengzuopeng）chips 模块](https://stock-sdk.linkdiary.cn/api/chips)（TypeScript 纯移植 + 文档化的算法与输出示例）、[动手学Python量化01：复刻A股筹码](https://www.cnblogs.com/huajiesoft/articles/20632494)。
- **实战用法**：获利比例>90% 且集中度低 = 高位套牢区（反弹抛压）；获利比例低+平均成本贴近现价+集中度高 = 主力锁仓（洗盘尾声）；筹码单峰密集上移 = 换手接力。
- **落地难度**：中（算法移植为主，无接口依赖问题）；**建议先移植 stock-sdk 的 TS 实现到纯 Python**，产出指标直接供 4.0 的"资金面评分"使用。

## 六、接入方式与工程要点（纯标准库约束）

1. **全部 HTTP 接口 = urllib.request / json / re 即可**，零第三方依赖；仅通达信 TCP（五档+逐笔）需要第三方库，若坚持纯标准库则用"腾讯五档 + 新浪历史逐笔"替代。
2. **东财限流铁律**（社区实测 + a-stock-data 文档）：串行请求、间隔 ≥1s+随机抖动、复用 Session、带 UA 与 Referer（`https://quote.eastmoney.com/`）；1 分钟 ≥200 次或单 IP 并发 ≥10 会封 IP。**实测印证**：push2 clist/stock/get 对部分 IP 间歇重置，但 `push2ex` / `fflow` / `datacenter-web` 各自独立风控，被封可降级。
3. **降级矩阵**：龙虎榜 → 沪深交易所官方（深交所 `szse.cn/api/report/ShowReport/data?CATALOGID=1842_xxpl`，上交所 `query.sse.com.cn/showTradePublicFile.do`）；资金流 → 新浪 MoneyFlow；五档 → 腾讯；涨停池 → 同花顺涨停揭秘。
4. **北向资金**：盘中实时已停（2024-08-19 起），日频权威走港交所官方 `hkex.com.hk/chi/csm/DailyStat/data_tab_daily_{YYYYMMDD}c.js`；项目现有东财北向持股可继续用于低频持股变化，但**不要把盘中"北向净流入"当实时信号**。
5. **数据落地**：建议按"东财 datacenter（日频）+ push2ex（日频）+ push2 资金流（盘中轮询，5~10 分钟一次）"三档频率调度，落 SQLite/JSON，避免频繁打东财。

| 1 | **个股+板块资金流** | 东财 push2 `fflow/kline/get`（分钟）、`fflow/daykline/get`（120日）、`clist/get` 板块（fs=m:90+t:2/3/1） | 主力/超大/大/中/小单全维度；板块轮动 + 资金背离信号，直接喂 4.0 资金面评分 | 低（纯标准库 HTTP） |
| 2 | **涨停四池 + 情绪温度计** | 东财 push2ex 四池（实测 2026-08-14 可用）+ 同花顺涨停揭秘 | 涨停家数/连板梯队/炸板率/晋级率/涨停原因/封板质量 —— 打板与题材情绪的唯一免费全套 | 低 |
| 3 | **龙虎榜深化** | 东财 datacenter `RPT_DAILYBILLBOARD_DETAILSNEW` + `RPT_BILLBOARD_DAILYDETAILSBUY/SELL` + 本地游资映射表 | 机构净买、游资席位跟踪、三日榜、净买额排名；与项目现有 datacenter 接入同款，改动最小 | 低 |
| 4 | **Level-2 近似：腾讯五档 + 新浪逐笔** | `qt.gtimg.cn`（五档，实测）+ `transHis.php`（历史逐笔，实测存活） | 盘口强度、主动买卖比、逐笔验证资金流；纯 HTTP 零依赖，不封 IP | 中 |
| 5 | **本地 CYQ 筹码引擎** | 东财 push2his 日K（含换手率）+ 自移植 CYQ 算法（参考 akshare/stock-sdk） | 获利比例/平均成本/集中度 —— 成本分布维度，与资金流形成"钱+筹码"双验证 | 中 |

**落地顺序建议**：1、2、3 可并行先行（全部东财 HTTP、一周内可通）；4 作为行情底座补强；5 放在 4.0 二期（算法移植工作量最大但独有性最高）。
