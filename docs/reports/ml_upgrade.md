# Phase 23：ML 选股升级报告（rank 标签 + 滚动训练 + 主力池验证）

- 时间: 2026-08-23
- 目标: ML 选股从"打分加分项"升级为"主力选股池"，并用历史窗口严格验证（IC + 回测对照）
- 结论先行: **IC 有价值（ICIR 1.316、十分组单调），但主力池回测不满足接入条件 → 不接入实盘，
  保留加分模式（默认）**；交付滚动训练工具 + ml_pred 表 + 验证报告

## 1. 标签升级与滚动训练（严格 PIT）

### 1.1 标签
- 原: 未来5日**原始收益**回归（极端值敏感）
- 新: 未来5日收益 → **当日横截面 rank 归一化 [0,1]**（组内排除 NaN；当日有效票 ≥15 才计，
  否则剔除——避免稀疏日 rank 失真）；排除 DATA_EXCLUDE_CODES

### 1.2 滚动训练（tools/ml_sidecar/rolling_train.py，venv）
- 交易日序列（取 kline 实际日期）；**每 20 个交易日一个训练点 T**
- 只用 **date≤T** 样本训练 LightGBM（n_estimators=200, lr=0.05, leaves=31）
- 预测 **(T, T+20]** 每日全市场横截面分；训练样本 y.std()<0.05 防御性跳过
- 落库 market.db **ml_pred(code,date,score) PRIMARY KEY(code,date)**，INSERT OR REPLACE 分批短事务
- **断点续跑**（data/ml_rolling_progress.json）；覆盖 2019-08-29 ~ 2026-08-14
- 执行: 全量 **800 只**（按 2026-08 成交额排序取前 800，流动性优先）→ **121.4 万行、785 票、1687 日、85 训练点**，总耗时 33 分钟
- 面板并行构建（8 worker）；不改 alpha158 特征

### 1.3 修复的关键 bug（rank 标签语义）
- 初版逐票算 rank → 单日只有 1 票 → rank 全 1.0（score 全 1.0 垃圾数据）
- 修复: **fwd5 先逐票算出，concat 后跨票按日期截面统一 rank**（当日 ≥15 票）
- 验证: score 分布恢复连续（min 0.13 / max 0.77 / mean 0.50）

## 3. 回测集成（engine ML_POOL_TOPN）

- engine 新增 `ml_pool_topn` 参数（params）：第 t 日选股池 = ml_pred 中 **date≤t 的最新预测
  top-N**（严格 PIT：只用在 t 日可得预测；按日缓存）；None=禁用（默认全池）
- `_ml_top_codes(date)` 查 ml_pred（sqlite3 只读）；`_signals_on` 过滤

## 4. 对照回测（top500 基线 vs ML top-100）

池与 Phase21 一致（top500、排除 DATA_EXCLUDE_CODES）；独立进程 import app.engine。

| 策略 | 窗口 | base | ML top-100 | Δ |
|---|---|---|---|---|
| score | 2019-20 | -7.65% | **-0.37%** | +7.28pp |
| score | 2021-22 | -21.59% | -38.31% | -16.72pp |
| score | 2023-24 | -36.95% | **+5.18%** | +42.13pp |
| score | 近一年 | +30.68% | +6.73% | -23.95pp |
| board | 2019-20 | -11.77% | **+14.76%** | +26.53pp |
| board | 2021-22 | -6.65% | **-3.02%** | +3.63pp |
| board | 2023-24 | -1.66% | -8.61% | -6.95pp |
| board | 近一年 | +27.30% | +3.87% | -23.43pp |

**★ 归因修正（交易数实证，见 data/bt_ml_compare.json）**：

| 策略 | 窗口 | base 交易 | ml 交易 |
|---|---|---|---|
| score | 2019-20 / 2021-22 / 2023-24 / 近一年 | 1331/1540/1332/809 | 817/1052/884/415 |
| board | 2019-20 / 2021-22 / 2023-24 / 近一年 | 628/747/616/448 | **117/140/49/12** |

- **board × ML top-100 交易样本崩塌**（12~140 笔 vs base 448~747）——打板信号与 ML top-100
  交集极少，收益对比**不可比**（如近一年 ml 仅 12 笔 +3.87%，无统计意义）。
- **2019-20 窗口 ml_pred 自 2019-08-29 才有**（2019-01~08 无预测 → ML 池前 7 个月为空，
  该窗口 ml 交易少），base 满窗口 vs ml 半窗口，亦不完全可比。
- **score 各窗口 ml 交易 415~1052 笔（较接近 base）**——score 的对照相对可比；
  但近一年 score ml 415 笔仍少于 base 809 笔，池缩小本身即改变交易结构。
- 原报告"ML 偏好低波动防御票、牛市进攻性不足"的归因**无持仓特征证据，予以删除**；
  近一年恶化主因是**池缩小 + 交易样本减少**而非可验证的选股风格差异。

## 5. 接入判定（规则事先写死：≥3/4 改善或持平 + 牛市恶化≤2pp）

| 策略 | 改善/持平 | 条件1 | 牛市Δ | 条件2 | 判定 |
|---|---|---|---|---|---|
| score | 2/4 | ❌ | -23.95pp | ❌ | **不接入** |
| board | 2/4 | ❌ | -23.43pp | ❌ | **不接入** |

**结论: 不接入实盘**（ML_POOL_MODE 不新增，维持现有加分模式 + SENTIMENT 等不变）。
- **IC 层面有价值**（ICIR 1.316、十分组单调），但**选股池化（top-100）在回测中未转化为
  稳健超额**——主要受交易样本崩塌（board）与池缩小（score）限制，无法判定"模型选股能力"
  在实盘中优于 top500 全池。**诚实结论: 本轮不接入**；后续研究方向:
  ① ML 池只做**加分/评分权重提升**（保留全池扫描，模型分作为多因子之一）——
     规避 top-N 截断导致的交易结构剧变；② 或验证 ML 池在更长样本/不同牛熊的稳健性
- 工具与数据保留（rolling_train / ml_pred / IC 验证 / engine.ml_pool_topn 均可复现）

## 6. 幸存者偏差说明
- 股票池仅含当前在市股票（2019-2026 退市股不在库），历史回测天然偏乐观；
- ML top-100 从 800 只流动性票中选，同样受限于该池
