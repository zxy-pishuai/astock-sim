## 4. 台账 1/20 慢的结构性分析

### 4.1 机制（读 `scores_ledger.py`）

- **登记**：`do_tick` 仅当 `ml_scores.json` 的 `date` 尚未登记时登记 1 个信号日（predict 单日单截面 → **1 信号日/日**为硬上限）。
- **兑现**：信号日 S 的 picks 需 S 之后 ≥1 交易日出现 T+1 bar 才有 realized return；8/26 信号日实测 40 票中 14 只 gap==1 兑现（35%），但 ≥8 已满足单日判据。
- **M3 判据**：20 个已实现信号日（每信号日 ≥8 兑现、双桶 ≥3）。

### 4.2 最短自然日测算（当前机制）

日频 predict（每日收盘后出新信号日）+ 日频 tick（16:30 登记+兑现）：

- 需 20 个不同信号日 + 最后一个信号日的 T+1 实现 → **21 个交易日**。
- 用项目交易日历（含 2026 休市：9/25 中秋、10/1-10/8 国庆）推演：
  - 若 predict 今日（8/31）以现有 kline 跑：首个新信号日=8/28，第 20 个已实现信号日 ≈ **2026-09-28**（自然日跨度 31 天）。
  - 若 predict 今晚收盘后起跑：首个新信号日=8/31，第 20 个实现日 ≈ **2026-09-29**（29 天）。
- 结论：**当前机制最短 ≈ 21 交易日 / ≈ 30 自然日（一个月）**，结构性慢成立。

### 4.3 加速选项与代价（只评估，不动代码）

| 选项 | 做法 | 代价 / 注意 | 建议 |
|---|---|---|---|
| **P1 并行登记（ml_pred 回填）** | 从 ml_pred 历史截面并行预登记（`--selftest-pred` 已证明管线可一次登记 25+ 截面、立即得 20+ 实现日，本次实测 25 日/join 1000） | ① 需改 `scores_ledger.py` 新增 backfill 模式写**真实台账**；② 混合产品①（ml_pred）进入产品②（ml_scores）账本，语义变化；③ 历史截面为「回溯登记」（PIT 有效但非前瞻）；④ 衡量的是 ml_pred 质量，非新 ml_scores | 可作为**独立的 ml_pred IC 快读**（该产品已有 `ml_ic_verify.py` 月度 IC 基线）；**不作为 B4 ml_scores 台账的替代** |
| **P2 predict 多截面输出** | predict 同时输出多历史截面 | predict 不保留历史分数，需大改；与主系统单文件原子写契约冲突 | 不推荐 |
| **提前兑现** | 让实现日早于 T+1 | 定义上不可能：realized return 必须等次日 bar。仅可放宽 M3 口径（gap≤2/3 计入、降 MIN_REPORT_DAYS），代价 = 前瞻有效性变弱 | 不推荐 |

**结论**：在「保持 B4 ml_scores 前瞻语义」的前提下没有捷径；加速只能靠（a）注册日频 predict 让信号日逐日前进，或（b）另起 ml_pred 并行 IC 快读（P1，需先获批改代码）。

## 5. 恢复方案建议（只建议，本批不执行、不注册）

### 5.1 建议 A：`predict.py` 注册为日频计划任务

- **时序**：数据更新之后、台账 tick（16:30）之前。规避 backlog「台账先落账」时序陷阱同类——predict 若晚于 tick，台账多等一天（正是 8/29/8/30 推进 0 的成因）。
- **.cmd 草案**（纯 ASCII、`%~dp0` 定位、绝对 sidecar 解释器；照抄 `tools\ml_scores_ledger_daily.cmd` 模式，仅替换解释器与脚本）：

```bat
@echo off
rem ML predict daily: refresh data/ml_scores.json (atomic overwrite). Pure ASCII.
rem Uses sidecar venv python (isolated lightgbm/pandas). Must run AFTER close
rem data update and BEFORE ml_scores_ledger 16:30 tick.
cd /d "%~dp0.."
set PYTHONIOENCODING=utf-8
set PYTHONPATH=%~dp0..\tools\ml_sidecar
"%~dp0..\tools\ml_sidecar\.venv\Scripts\python.exe" tools\ml_sidecar\predict.py --codes 2000 >>data\ml_predict_cron.log 2>&1
```

- 若放夜间（如次日 04:00），则次日 16:30 tick 登记**前一日**信号日，进度仍 1 日/日，可接受。
