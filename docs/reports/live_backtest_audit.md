# Phase 45 报告：trader.py ↔ engine.py 一致性审计（只读）

- 状态：**已完成**（纯只读审计；本报告为唯一新增文件，未改任何代码）
- 对象：`app/trader.py`（实盘模拟，1,337 行）↔ `app/engine.py`（回测，1,257 行）
- 方法：按任务清单 8 项逐一对照源码（文件:行号引用），三态评级
  （一致 / 漂移 / 缺失），严重度分 **致命 / 中 / 低**

---

## ⚠️ 置顶：致命差异（修复前，以下回测结论对模拟盘**不可外推**）

### 【致命-A】实盘独有"市场环境+情绪周期"动态闸门，回测完全没有
- 实盘：`trader.py:405-446` —— 每轮扫描按涨跌占比算 regime，**动态改变最大持仓数与
  买入阈值**（`sc.get_regime`），再叠加情绪周期：冰点/退潮 `max_pos=0` 整段禁买、
  高潮期放宽阈值 −5 并扩持仓、发酵期收紧（L407-424）。
- 回测：`engine.py` 全程使用静态 `MAX_POSITIONS=3` 与静态 `BUY_SCORE_THRESHOLD`
  （L115-116），**不存在任何环境自适应逻辑**。
- 影响：实盘的可交易机会集是回测信号集的严格子集，且买卖时点分布完全不同。
  **score 回测的绝对收益、回撤、胜率对模拟盘均不可外推。**

### 【致命-B】打板专属退出规则仅存在于实盘，board 回测没有
- 实盘：`trader.py:1117-1136` —— 打板仓（`board_trade=True`）T+1 次日：
  低开 ≤`BOARD_NEXT_DAY_LOW` 即止损、浮盈 ≥5% 即半仓止盈、次日过后转普通持仓。
- 回测：`engine.py` board 策略走通用退出链（L404-484），**没有任何打板专属退出**，
  也没有 `board_trade` 标记。
- 影响：**Phase30/44 等 board 回测的全部收益/回撤结论，对实盘打板行为不可外推**
  （实盘会在回测继续持有的场景里止损/减仓，反之亦然）。

### 【致命-C】实盘买入决策链比回测多出七道过滤器与加分项
实盘自动买入前依次经过（`trader.py` 行号）：成交额硬门槛 `amount≥8e7`（L461）、
两级粗筛池 top80+quiet20+focus+领涨（L467-485）、自选股 +10/板块抱团 +10/龙头 +5
（L496-504）、资金面加分重排序（L509-533）、组合硬风控 `rk.engine.check_buy`
含单票上限与日度限额（L614-620）、分时量双阈值拦截（L621-632）、共识投票看空
拦截（L633-642）。**以上在 engine.py 的 `_signals_on`(L356-401) 与买入循环中一概不存在。**
- 影响：同一只票在两侧可能得到不同评分（加分项）、甚至一侧根本不产生信号
  （过滤项）。**任何以回测信号清单推演"实盘会买什么"的做法都不成立。**

## 逐项对照表（任务清单 8 项）

### 1. 买入成交价 —— 漂移（中）
| | 实现 |
|---|---|
| engine | `open×(1+slippage)` 后经 `execution.execute_price(..., impact=True)`（L618-650，真实委托量 `px*qty`、当日成交额参与冲击成本），另有涨停排队概率模型 `queue_fill_prob`（L652-659，exec_prob 默认开） |
| trader | `_buy_px` L301-318：`execute_price(price, side, mcap, amount=price*1000, day_amount=0, **impact=False**)` —— 冲击成本关闭、数量固定假设 1000 股；异常时静默回退固定 `±SLIPPAGE`；随后钳制在涨跌停区间内（4.7 修复） |

同用 execute_price 但**参数不同**：impact 开关相反、amount 口径不同。另外引擎买入
基准是 T+1 开盘价，实盘是盘中实时价（结构性差异，见第 6 项注）。
**建议**：统一 impact 与 amount 口径；实盘传入真实 qty。

### 2. 卖出成交价与滑点方向 —— 漂移（中）
| | 实现 |
|---|---|
| engine | 卖出直接 `close×(1−slippage)`（L422/438/450/456/484/708），**不经 execute_price，无市值分档** |
| trader | `_sell_px → _buy_px(side="sell")`（L316-318, L1196-1197）：市值分档滑点 + 涨跌停钳制 |

微盘股上引擎卖出成本被系统性低估。**建议**：engine 卖出补 execute_price(impact=True)。

### 3. 费用 —— 一致 ✅
两侧同源调用 `eng.buy_fee / eng.sell_fee`（trader.py:325/351 ↔ engine.py:53-60），
佣金万 2.5 最低 5 元 + 印花税卖出 0.05% 完全一致。过户费口径注释一致。

### 4. T+1 —— 一致 ✅（粒度差异见第 6 项注）
engine：`pos["days"]<1` 禁卖（L416-417）；trader/state：`entry_date >= today` 拒单
（trader.py:343-345）。trader 另按交易日历重算 days（L1087-1095），语义等价。

### 5. 涨停/跌停处理 —— 漂移（卖出侧缺失，中→偏高）
- 涨停买入：engine 开盘涨停跳过（L616）+ 排队概率模型；trardor `px>=lu*0.999` 跳过
  （L594-599, L794-795）+ 封板识别提示（L1240-1253）。✅ 方向一致（模型 vs 真实撮合）。
- **跌停禁卖：trader 有（L1192-1195 `cp<=ld*1.001` 跳过）；engine 退出链完全没有跌停
  检查**（L404-484 直接按收盘价成交）。docstring 声称"跌停卖不出"但代码未实现。
  **建议**：engine._check_exits 补 `bar["low"]<=ld` 判定，无法成交则顺延——修复前，
  崩盘期（2020-03、2022-04 型）回测的回撤与退出成功率被高估。

### 7. 指数择时 / 情绪闸门 —— 一致 ✅（当前均关闭）
- 指数择时：engine `params.index_timing`（默认 False，PIT 用 prev_date，L585-596）；
  trader 读 `INDEX_TIMING_ENABLED`（False，L559-574）。开关状态一致 → 当前无漂移。
- 情绪仓位闸门：engine `SENTIMENT_POS_GATE`（False，L597-610）；trader 同名配置
  （False，L575-589）。同上 ✅。
- 但注意【致命-A】：trader 在这两个可关闸门之外，还有一层**永远生效**的情绪周期/
  regime 闸门，回测无对应物——那才是真正的裂缝。

### 8. 仓位计算 —— 公式一致 ✅（外围不一致已并入致命-C）
- 单仓公式两侧对齐：`min(min(w, RISK_SINGLE_STOCK_PCT*0.95), pos_pct)`
  （engine.py:577-584 ↔ trader.py:600-604，均带 Phase15 修复注释）；
- compute_weights 调用参数一致（method/target_vol/days 同源 config，trader.py:555-558
  ↔ engine.py:550-553）；
- 差异在外围：engine 有 dd_gate/zt_eco_gate 乘数（params 控制，实验外默认关）与
  行业敞口上限（L651-667）；trader 有 rk.check_buy 硬风控（并入致命-C）。当前默认
  配置下核心公式无漂移。

## 修复建议（仅建议，不实施；按投入产出排序）
1. **F（最小改动、最大可信度提升）**：engine._check_exits 增加跌停无法成交判定，
   无法成交顺延下一交易日——修复前所有回测的崩盘期回撤都被高估可信度存疑。
2. **E**：engine 卖出改走 execute_price（与买入对称），消除微盘股成本低估。
3. **B**：engine board 策略补打板专属退出（BOARD_NEXT_DAY_LOW 止损 + 半仓止盈），
   否则 board 回测应重新标注为"不含实盘风控的理论上限"。
4. **D**：trader._buy_px 传真实 qty 并打开 impact，与引擎口径对齐。
5. **A/C 属产品形态差异**（实盘天然比回测保守），不建议让回测模仿实盘过滤器，
   而是在回测报告中显式标注"未含实盘过滤链"，或把过滤链抽象成可注入回测的策略层。
