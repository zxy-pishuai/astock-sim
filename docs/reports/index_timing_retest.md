## 3. 解读（诚实）

1. **对 board 有效**：三个非牛窗口两个改善（+10.98/+2.74）、W1 仅 −4.52pp，
   牛市窗口几乎无代价（+1.05pp）。打板候选集中在高波动小票，指数空头期的
   缩仓恰好过滤了其最差交易环境。
2. **对 score 无效**：熊市窗口虽改善（最高 +12.76pp，证明择时确实在熊市起作用），
   但代价全部砸在牛市窗口（−8 ~ −15pp）。score 的收益集中段与降仓期重叠，
   MA20/60 判定在牛市震荡段频繁误降仓。
3. **空头乘数越激进牛市代价越大**（MD 0.8→0.7→0.6 牛市 Δ −8→−15.5→−6 不单调，
   但 0.7 最差），无免费午餐；现行 0.8 对 board 已够用。
4. **乘数生效占比偏高**（board 76%~100%、score 76%~100%）：该闸门不是偶发熔断
   而是"常态性缩仓"，其本质是长期半仓策略叠加择时倾斜——评估时应理解为
   风险敞口差异而不仅是退出技巧。
5. 与 P22 情绪闸门对照：情绪闸门（干净数据）判无效维持关闭；指数择时对 board
   有真实增益——两个"择时"结论从此分叉，均基于干净数据。

## 4. 判定（事先写死）

规则：≥3/4 窗口 Δ≥−1pp 且牛市恶化 ≤2pp 且非牛至少 1 窗改善 ≥3pp。

- **board + index_timing(现行参数 MD=0.8)：通过** → 建议开启。
  落地注意：config.INDEX_TIMING_ENABLED 是全局开关而 score 未通过，
  建议验收方按"仅 board 路径启用"处理（如 trader 打板路径单独接线或
  引入策略级开关），直接全局开启会使 score 承受 −8.05pp 的牛市代价。
- score 各配置均不达标 → score 维持关闭。
- 本阶段未修改任何文件（tools/data/docs 新增除外）。
