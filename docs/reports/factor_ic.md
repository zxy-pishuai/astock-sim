# Phase 28-A：score_stock 打分因子 IC 审计（只读）

- 时间: 2026-08-24
- 工具: tools/factor_ic_audit.py（纯标准库，可复跑，86 秒全历史）
- 数据: data/factor_ic_audit.json
- 结论先行: **18 个 K 线成分中仅 1 个有效（还是罚分项）、5 个弱、12 个负**。
  现有手工权重的主体方向与 A 股短线反转效应相反——"追强势"类加分因子
  （量价齐升/突破/RSRS/均线多头/量价相关/放量启动）在 top500 池内对未来 5 日
  收益具有稳定的**负**预测力。阶段 B 触发条件（≥2 负或 ≥3 弱）成立。

## 1. 方法

- 样本池：data/bt_pool.json 前 500（排除 DATA_EXCLUDE_CODES），与回测口径一致
- 标签：fwd5 = close[t+5]/close[t] − 1（个股自身 bar 序列，同 ml_ic_verify 规则）
- PIT：全部引用指标为因果纯函数（indicators.py），t 日成分只用 ≤t 数据；
  未来收益只存在于审计标签中
- IC：日频横截面 Spearman（成分带符号分值 vs fwd5）。成分为二值触发，
  用秩和法精确还原含并列平均秩的 Spearman（200 组随机试验与直接实现一致，
  误差 <1e-9）；单日样本 <30 或任一组 <3 不计
- 聚合：月度 IC = 月内日 IC 均值；ICIR = 月度均值/月度标准差(ddof=1)；
  分类：有效 ≥0.3 / 弱 0~0.3 / 负 <0
- 二值信号的"五分位单调性"退化为触发/未触发两组对照（spread），逐年价差见 JSON

## 3. 解读（诚实）

1. **负 IC 主因是 A 股短线反转效应**：追涨类因子触发即股价已处短期高位，
   未来 5 日平均跑输横截面。这不是数据错误——volume_price/breakout/vp_corr 等
   的月度 IC>0 占比仅 25~35%，方向在时间上相当一致。
2. **唯一有效成分是罚分项**（vp_divergence）：说明现有体系里"减分"比"加分"
   更有证据支撑。
3. **罚分项 penalty_overbought 方向反了**（ICIR −0.26，spread +27bp）：RSI>70
   的票未来并未更差，扣分反而错杀强势票。
4. 弱正因子集中在"超卖回升/缩量回踩"一类低吸形态，与反转效应自洽。
5. 注意事项：审计对象是"二值触发的方向正确性"，不是打分阈值校准；
   IC 为全期聚合，结构变化（风格切换）见 JSON 中逐年 spread。
