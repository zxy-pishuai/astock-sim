## §1 改动清单

| 文件 | 内容 |
|---|---|
| `tools/bench_fixtures_build.py`（新建） | 从快照库只读导出 3 票×1250 根 → `data/bench_fixtures.npz`（可重复跑重建；600000 浦发银行/002001 新和成/300750 宁德时代，2021-07-20~2026-09-11） |
| `tools/bench_score.py`（新建） | 离线指标基准：score_stock 热态（预热 10 + 300 次中位数）、函数调用数（sys.setprofile 计数）、17 个 indicators 单项（50 次中位数）；比对基线 >+20% 非 0 退出 |
| `tools/bench_backtest.py`（新建） | 离线回测基准：`_load_data` 耗时、`_signals_on` 窗内 5 交易日中位耗时、`run()` 3 次中位总耗时、tracemalloc 峰值内存（近1年窗）；比对 >+20% 非 0 退出 |
| `data/bench_fixtures.npz`（新产物） | 3 票 × 1250 根日K（date/open/high/low/close/volume/amount 结构化数组） |
| `data/bench_baseline.json`（新产物） | 性能锚点：score 段 + backtest 段（首次自动写；之后只比对不自动刷新，`--update-baseline` 显式更新） |

**设计要点**：
- **基线是固定锚点**：日常运行只比对不写；性能改造完成后人工 `--update-baseline` 刷新（否则回归护栏会跟着退化漂移，失去守护意义）。
- **降噪三板斧**（任务书允许的"降低噪声"手段）：① `gc.disable()` 计时段（H2 已知 GC 风暴是主要噪声源——**实测关闭后 backtest total 从 1.6~2.0s 降到 0.40s**）；② numpy/BLAS 固定单线程环境变量；③ 热态多次取中位数（score 300 次、backtest total 3 次）。
- **完全离线**：score 只读 fixtures npz；backtest 只读快照 + `BT_NO_CACHE=1`（不依赖缓存命中状态，逐次确定性一致）。

## §3 稳定性验证（J2）

| 脚本 | 3 次结果 | 最大波动 |
|---|---|---|
| bench_score（预热 10 + 300 次） | 5.68 / 5.46 / 5.74 ms | **4.9%** |
| bench_backtest（total 3 次中位） | 0.361 / 0.416 / 0.399 s | **13.2%** |

均 ≤15%。**降噪过程记录**（首次裸跑波动 43%/19% → 降噪后 4.9%/13.2%）：
1. 裸跑：score_stock 7.85→5.59→4.48→4.89（波动 43%）→ 判据不可用；
2. 排查确认 score_stock 内部**零 IO**（源码扫描无 sqlite/fetch/urllib/requests/open），波动源为 GC + numpy 线程竞争 + 并发机器负载；
3. `gc.disable()` + BLAS 单线程 + 预热 10 次 + 300 次中位数 → 波动 4.9%。

## §5 离线说明（J1）

- `tools/bench_fixtures_build.py` 只在**重建 fixtures** 时读快照库（一次性）；bench_score 运行时零 IO（纯内存计算）。
- bench_backtest 运行时只读 `data/snapshots/2026-09-11/market.db`（`file:...?mode=ro&immutable=1`）+ `BT_NO_CACHE=1`（跳过 bt_cache 与网络降级路径）→ 断网可复现。
- 两脚本均无 urllib/requests/行情源调用（代码扫描确认）。

## §7 诚实披露

1. **backtest 峰值内存 2.7MB 仅代表 3 票小样本**：tracemalloc 追踪 Python 分配，大池（1500 票）峰值另见 H3 报告（估算 1-1.5GB）；本基准定位是"回归护栏"，不是全规模内存仪表。
2. **波动 13.2%（bt total）接近 15% 上限**：并发机器负载是主要残余噪声；若未来超限，建议固定进程 CPU 亲和性或错峰运行（夜间任务天然低竞争）。
3. **scoring.py 的临时注入已恢复**（SHA256 match），但按 H 道红线本不应碰 I 道文件——本次是任务书 J3 判据明确要求的临时测试动作，恢复后零残留，特此说明。
4. **基线只锚定 2026-09-11 快照**：快照库被替换/删除后需重新 `bench_fixtures_build.py` + 双脚本 `--update-baseline` 重锚（fixtures 已固化 3 票 1250 根，不依赖快照持续存在）。
