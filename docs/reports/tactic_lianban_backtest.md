## §0 判据预注册（先落盘后跑数，跑完不改）

**涨停重建（游资通行口径，与 pack12 W1 同款）**
- 涨停：`chg = close_t/close_{t-1} - 1`；主板(60/00)≥9.7%、创业/科创(30/68)≥19.4% 记涨停日。
- 除权粗处理：`|chg| > band`（10%板 0.117 / 20%板 0.214）时，t-1/t/t+1 三日均不判涨停。
- 新股豁免：上市前 5 个交易日不参与涨停定义（seq<5，chg 基数不稳）。
- 连板数 `lbc`：连续涨停日计数，中断归零；`next_lbc` = 下一交易日连板数。
- 口径自证：比值判据在 qfq 恒定比例放大的价格方言下幸存。

**三问判据**
- 问① 晋级率 P(n→n+1)：事件级 = `next_lbc == n+1` 占比，按年 × 全期 × IS/OOS 分列。
- 问② 一进二扣费后正期望：三种打法（A1 打板 / A2 开盘追 / A3 断板低吸）× 卖点网格，**胜率A = 扣费后收益>0 占比**，样本<100 标"不可信"。
- 问③ 情绪闸门：按 `qg_zt_full.phase` 分期的晋级率与打法净收益对比。

**成本（固定写死，拍脑袋参数，披露）**
- 佣金 0.025% 双边 + 印花税 0.05%（卖） + 滑点 0.2%/笔（买卖各一）。
- A1 打板额外 +0.1% 排队成本惩罚。买入成交价上浮、卖出下浮；无其他摩擦。
- 敏感性：A1 成交现实性另加 +0.1%~+1.0% 买入成本测试（见 §7）。

**打法定义（buy day = T 指"买入日"）**
- **A1 打板**：n 板日（t）收盘涨停视为成交（买入价=收盘涨停价），**一字板剔除**（排不进）。买入日=t。
- **A2 竞价/开盘追**：t+1 日开盘买，**剔除 t+1 开盘即一字**（`next_board_type=='一字'`）。买入日=t+1。
- **A3 断板低吸**：断板日（连板中断首个非涨停日）开盘买；盘中 -3% 挂单近似：`low ≤ 开盘×0.97` 则按 0.97×开盘成交，否则按开盘成交。买入日=断板日 b。
- **卖点网格（T = 买入日）**：`next_open`（T+1 开盘）、`next_close`（T+1 收盘）、`break_next`（连板终止后次日开盘；A3 为 b+2 开盘）。三卖点各自独立回测（非时序切换）。
- 三打法样本数天然不同，逐行并列。

**正确性门（决定性，P72）**：重建 lbc 与 `limit_pool.payload.lbc` 在重叠窗逐票逐日对表，一致率≥95% 才算重建可信；不达=如实报"未就绪"。

**终判口径（§3 网格在 IS 选参，§4 OOS 一次性终验）**：最优打法须 IS 与 OOS 均扣费后净收益>0 且逐年不出现系统负期。

## §0.5 正确性门（结果：通过，97.83% ≥ 95%）

### 对表范围与方法
`limit_pool(kind='zt')` 1303 行覆盖 20260815~20260902。**快照 kline 自 2026-08-24 起稀疏**（08-21 完整 2108 票 → 08-24 1367 → 09-02 462），且 limit_pool 是**滚动池**（date 含周末重复、含断板股、含实盘有新 kline 但快照无行的新股）。因此对表聚焦**干净窗口 2026-08-14~08-21**（kline 完整、池数据可靠），并对齐 pool.date→kline 交易日（经验对齐表：08-15/16→08-14、08-18→08-17、08-19→08-18、08-20→08-19、08-22/23→08-21 等）。

### 结果
- **干净窗口（08-14~08-21，705 行，排除北交所 92 的 5 行）**：
  - 有重建 zt 记录 552 行 → **lbc 一致率 = 97.83%（540/552）≥ 95% → 通过**。
  - 153 行无重建记录：**全部为池内股票在快照 kline 无 bar**（停牌或快照缺；抽查 002811/001260/002658/603177 在快照 kline 全表 0 行）。池来自实盘 feed，快照 universe 不含——属**数据源差异，非重建错误**（无 bar 即无涨停可能，重建正确）。
  - 12 行 lbc 不一致：11 行 `my = true+1`（池 lbc 为入池时陈旧值，重建为当前连板数，如京粮控股 true=2 my=3）+ 1 行对齐差一天假象（南京商旅）。
- **经验对齐表多个池日与重建 100% 重合**（08-26→08-25 49/49、09-01→08-31 40/40、09-02→09-01 46/46），涨停集合识别零差异，佐证重建正确。
- 北交所 92 开头 12 行按设计剔除（重建仅覆盖 60/00/30/68）。

### 差异归因（三类）
| 类别 | 占比 | 归因 |
|---|---|---|
| 一字板判定 | 0 | 无差异（is_zt 与池的涨停集合在干净日全重合） |
| 除权剔除 | 0 | 干净窗无除权断层日冲突 |
| limit_pool 自身口径 | 12 行 + 153 行 | 陈旧 lbc / 滚动池混日 / 新股与停牌股快照无行 |

**结论：重建的涨停识别（is_zt）与连板数（lbc）在数据完整段可信；残余噪声全部可归因于 limit_pool 自身口径，非重建缺陷。**

- 涨停家数（zt_count）三分位与涨停溢价（prev_zt_premium）三分位对晋级率影响弱（17-19% 区间），**情绪闸门作为一进二的硬过滤无增益**（这也是推荐卡里 `sentiment_gate.enabled=false` 的原因）；真正的闸门价值在于区分打法（高潮期禁开盘追）。

## §7 诚实披露

1. **幸存者偏差（16-32pp 语境）**：快照 kline 无退市股，全部收益（含推荐组合）在真实可交易历史上可能被系统性高估。A1 的绝对值应视为上限。
2. **ST 不可识别**：无 ST 标记，ST 股连板混入样本；其 5% 涨跌停被按 10% 判据过滤（ST 涨停 chg≈5%<9.7% 不会误判），但 ST 股在正常日也会被计为"未涨停"参与分母，影响轻微。
3. **打板成交近似（最大乐观源）**：A1 以收盘涨停价"视为成交"，实际排队买入可能买不到（尤其强封单）。已加 0.1% 排队惩罚；**敏感性测试（额外买入成本）**：
   - +0.3% → IS +2.26% / OOS +1.97%；+0.5% → IS +2.05% / OOS +1.77%；**+1.0% → IS +1.55% / OOS +1.27%（仍为正）**。
   - 结论：A1 结论对排队成本容忍至 +1% 仍稳健。
4. **A2/A3 的成交现实性**：A2 开盘买在真实可成交性上合理（非一字即可竞价），但结果仍为负——不是成交近似造成的，是策略本身负期望。
5. **"炸板未封"板型重建缺陷**：我的 is_zt 要求收盘达涨停阈值，因此真正的"冲板炸开收于下方"日不计入首板事件（仅 33 个浮点边界样本）。**炸板未封作为首板特征在本数据上不可测**；与三周真值因子里的 zbc（炸板次数）是不同维度。
6. **limit_pool 仅三周（1303 行）**：只做正确性门与方向性体检，**不能当结论**。
7. **min5 残缺 → 首封时间 fbt 历史无法重建**：fbt 仅三周真值可用，历史网格没有 fbt 因子。
8. **三周真值因子体检（20260815~0902，方向性、样本小、不宣称显著）——次日晋级率方向表**：
   | 因子 | 方向 |
   |---|---|
   | 封单/流通市值 fund_ltsz | 单调正：<1%→10.1%，1-3%→15.8%，3-10%→29.8%，>10%→46.2% |

## §8 给 V2 的接口节（状态机）

**连板梯队状态机（供 V2 逐字引用字段名）**

```
事件源: kline(day) + qg_zt_full.phase
board.{limit_main=0.097, limit_gem=0.194, new_list_exemption_days=5}

每交易日 per 票:
  1. 涨停判定: chg>=board.{limit_main|limit_gem} (按代码前缀60/00→main,30/68→gem; 上市<5日豁免)
  2. 连板状态: lbc = 连续涨停计数 (断板归零); 事件 = {一板: lbc==1, 二板: lbc==2, 三板: lbc==3, 高度: lbc>=4}

  4. 买点触发:
     - A1(打板): lbc>=1 且 board_type!='一字' 且(可选 filters) → 收盘挂单买入 (sealed_at_close=true)
     - A2(开盘追): t+1 开盘买入, 剔除开盘一字(yizi_exclude=true)
```

## 附：结论摘要

- **正确性门**：97.83%（干净窗口 540/552）≥95% 通过。
- **全期 P(1→2) = 17.71%**；IS 16.99%、OOS 18.64%。
- **最优打法一句话**：收盘打缩量首板、次日开盘卖，扣费后 IS +2.56% / OOS +2.28%、胜率 ~70%，8 年逐年为正；开盘追与断板低吸均为负期望。
- **连板梯队成不成立**：**成立但有边界**——晋级率随板高单调上升（1→2 仅 18% 但 4 板+ ~54%）的梯队结构真实存在；但**一进二只有"打板+隔夜卖"这一种吃法赚钱**，竞价追高和断板低吸在 2019-2026 全样本上都是亏钱的（负期望），情绪高潮期对开盘追更是接盘重灾区。结论：连板可做，但只做缩量首板隔夜这一种形态，且要接受买不进（成交现实性）与幸存者偏差高估的双重打折。
