# Phase 17 封板质量评分 + 持仓炸板提醒报告

- 目标: 打板评分充分利用封板质量信息（首封时间/封单资金比/炸板次数），并补持仓炸板提醒
- 状态: 完成；默认保守权重；炸板提醒默认开（只提醒不自动卖）
- 环境: 纯标准库、compile 通过、服务未重启

## 1. 评分公式与权重

### 1.1 封板质量子分 `seal_quality_bonus`（app/scoring.py）
从涨停池（`limit_up_pool`，东财 getTopicZTPool）取 fbt/fund/ltsz/zbc 计算：

| 因子 | 规则 | 权重（默认） |
|---|---|---|
| 首封时间 | ≤10:00 加分 / 10:00-13:30 中性 / ≥14:30 尾盘减 | `first_seal: 8` |
| 封单资金/流通市值 | 三档：≥P80(1.9%) 强 / ≥P50(0.9%) 中 / 弱 | `seal_ratio: 6` |
| 炸板次数 | 0 次加 / 1 次中性 / ≥2 次减 | `zhaban: 6` |

- 连板高度沿用现有 `leader_score`/`score_board` 逻辑，**不重复计分**
- **权重可全设 0**（`BOARD_SEAL_QUALITY_WEIGHTS={}`）→ 子分恒 0，行为与现状完全一致
- 接入点：`score_board` return 前（取 quote.code → 查涨停池）；实盘 `_board_round` 生效；
  回测 board 模式无实时涨停池与 quote.code → 不触发（如实：回测无法验证封板质量）

### 1.2 封单资金比阈值（用 limit_pool 历史分位，实测 500 样本）
- P50 = 0.90% / P80 = 1.87%（均无 ltsz 缺失）
- 阈值: `BOARD_SEAL_RATIO_MID=0.009`（≥0.9%）/ `BOARD_SEAL_RATIO_HIGH=0.019`（≥1.9%）
- 首封: `BOARD_FBT_EARLY=100000` / `BOARD_FBT_LATE=143000`

## 2. 历史验证（limit_pool 快照 2026-08-15~08-23，如实说明验证程度）

⚠️ **limit_pool 实测仅存 9 天快照（710 行，2026-08-15 起）**，非任务预期的"2025 至今"。
字段完整（fbt/lbt/fund/zbc/zttj/ltsz/hs 均有），294 个样本有次日收益，结论如下：

| 维度 | 组 | n | 次日均溢价 | 胜率 |
|---|---|---|---|---|
| 封板质量总分 | 高(bonus>0) | 232 | **-1.30%** | 37.9% |
| | 低/负(bonus≤0) | 62 | -2.32% | 33.9% |
| 首封时间 | ≤10:00 | 159 | **-1.15%** | 37.7% |
| | 10:00-14:30 | 118 | -1.92% | 36.4% |
| | ≥14:30 尾盘 | 17 | -2.08% | 35.3% |
| 炸板次数 | 0 次 | 134 | **-0.90%** | **40.3%** |
| | 1 次 | 85 | -2.26% | 32.9% |
| | 2 次 | 28 | -0.49% | 42.9% |

**结论（如实）**：
- **方向支持加分设计**：封板质量高分组的次日溢价优于低分组（-1.30% vs -2.32%）、
  首封早更好、零炸板胜率最高 ✓
- **局限**：样本仅 294（9 天快照、单月窗口、该时段大盘系统性下跌致次日全负）；
  炸板 2 次组胜率反常高（n=28 小样本噪声）。**属方向性支持，统计显著性有限**，
  需更长历史快照（后续每日落库积累）复验。

## 4. 持仓炸板提醒

- 检查结论: 现有 `_exits_round` 的"冲高回落止盈"（峰值回落≥2% 自动卖）**间接覆盖**炸板后回落卖出，
  但**无独立炸板提醒**。
- 新增: `trader._exits_round` 中对打板持仓（`board_trade`）检测——曾封涨停（peak≥涨停价×0.99）
  且现价跌破涨停价≥0.5% → **提醒（event + 微信推送），不自动卖出**；15 分钟冷却防刷屏
- 开关: `BOARD_BREAK_ALERT=True`（默认开，只提醒不自动卖；`BOARD_BREAK_DROP=0.005`）
- 与回落止盈并存不冲突：止盈管"卖"，提醒管"看"

## 5. 默认开关状态

| 配置 | 默认 | 说明 |
|---|---|---|
| `BOARD_SEAL_QUALITY_WEIGHTS` | first_seal=8 / seal_ratio=6 / zhaban=6（保守）| 设空则不生效 |
| `BOARD_BREAK_ALERT` | True | 只提醒不自动卖 |
