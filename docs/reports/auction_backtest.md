## §0 判据原文（预注册，跑完不改）

**主口径 = 日线近似**（报告中明示"近似，非真竞价数据"）：

- **事件宇宙与切分**（沿用已证口径）：`event_mask(pre=7, brk=20, vol='OR', trend=True)`，IS=2019-01-01..2023-12-31、OOS=2024-01-01..2026-08-31。
- **竞价打板臂**：事件 t 次日（t+1）满足 `开盘缺口 apct∈[+3%,+9.8%)`（apct=t+1 开/昨收−1）且 `量比≥1.5` → t+1 开盘买入；卖出 = yang9_M（持有期首个 chg≥0.09，封板次开卖，否则 14 日强卖）；扣费 `(1-SELL_COST)/(1+BUY_COST)*ret-1`。t+1 开盘即封板（买不进）剔除并计数。
- **弱转强臂**：昨日涨停（t 日 is_zt）+ 今日低开 `apct∈[−3%,+1%]` + 量比≥1.2 → 开盘买，同上卖出与剔除。
- **基线** = 同宇宙盲买 E1（C2b 口径：IS 4432 / OOS 3093，直接引用并复核）。
- **判过**：某臂 IS 与 OOS 双段期望 ≥ 基线−0.1pp，且至少一段期望 +0.5pp 或胜率 +2pp（该段 n≥300）；另需 OOS 分年（2024/2025/2026）方向不反转。
- **多臂/多阈值组合（预注册，不许跑完再加）**：
  - 打板 `[3,9.8)%×量比1.5`、`[2,7)%×量比1.2`
  - 弱转强 `[−3,1]×1.2`、`[−5,0]×1.5`
- **判不过**：如实报 null + 最接近臂与差距——两卡维持"公示参考"徽章，不进板块候选。
- min5 可得窗口内：对日线近似臂做触发一致率抽验（≥70% 记"近似可靠"，否则报告标注偏差方向）。

**量比 proxy 声明**（实现口径）：`vr = vol[t+1] / vol[t]`（**相邻日量比**）。真实竞价量比 = 竞价量/过去均量，日线近似下不可得，故用 t+1 全天量 / t 全天量作 proxy；阈值 1.5/1.2 直接套用于该 proxy（近似含义见 §4）。

**卖出实现**：复用 `tools/tactic_backtest.py::_sell_path(wc,wo,wl,wz,wchg, b=0, buy_price, start_price, V=1, H=14, S="none", band, yang=0.09, yang_at="M")`——与 C2b 基线完全同语义（封板次日开卖 / 未封板当日收卖 / 14 日强卖）。

**剔除（与 C2b 基线同口径）**：t+1 收盘涨停（`chg≥band`，买不进）+ 开盘价触及涨停价（日线近似"开盘即封板"；四臂 apct 上限恒 < band 故理论不触发）+ cyq no_cache/no_row/seam（同 C2b）。费用：BUY_COST=0.00225、SELL_COST=0.00275（tactic_backtest 常量）。

## §3 判定

**判过条件**（预注册，机械执行）：
1. IS 与 OOS 双段期望 ≥ 基线−0.1pp（IS ≥ −1.97%、OOS ≥ +2.44%）；
2. 至少一段期望 +0.5pp（IS ≥ 基线IS+0.5pp=−1.37% 或 OOS ≥ 基线OOS+0.5pp=+3.04%）**或**胜率 +2pp（IS ≥ 44.04% 或 OOS ≥ 45.61%），该段 n≥300；
3. OOS 分年（2024/2025/2026）方向不反转。

| 臂 | cond1 双段期望 | cond2 boost | cond3 分年 | **结果** |
|---|---|---|---|---|
| 打板 A1 | ✗（IS −4.22% < −1.97%） | ✓ | ✗（2024 −3.37% 反转） | **null** |
| 打板 A2 | ✗（IS −2.66% < −1.97%） | ✓ | ✗（2024 −2.85% 反转） | **null** |
| 弱转强 B1 | ✓（IS −1.29% / OOS +3.06%） | ✓（IS −1.29% ≥ −1.37%） | ✗（2024 −0.87% 反转） | **null** |
| 弱转强 B2 | ✓（IS −1.80% / OOS +3.14%） | ✗（IS n=163、OOS n=184 均 <300） | ✗ | **null** |

**结论：四臂全 null。** 两卡维持"公示参考"徽章，不进板块候选。

**最接近臂与差距**：**弱转强 B1**（[−3%,+1%]×量比≥1.2）——
- IS −1.29% vs 基线 −1.87%（**+0.58pp**，超 +0.5pp 门槛）；
- OOS +3.06% vs 基线 +2.54%（**+0.52pp**）；
- OOS 胜率 47.04% vs 43.61%（**+3.43pp**，超 +2pp 门槛）；
- **唯一差距 = OOS 2024 年 −0.87% 方向反转**（2025 +1.02%、2026 +10.39% 均正向）。差距幅度约 3.9pp（2024 相对 OOS 总方向）。

**日线近似口径声明（限度）**：
1. **"竞价量比"被替换为相邻日量比** `vol[t+1]/vol[t]`——真实竞价量比（09:15-09:25 集合竞价量 / 过去 5 日均量）在日线近似下不可得；阈值 1.5/1.2 是套用于该 proxy 的近似，**不是**真实竞价口径。
2. **"t+1 开盘买入"假设开盘价可成交**——未建模真实竞价撮合（集合竞价能否成交、开盘瞬间滑点），仅剔除开盘价触及涨停价（`apct≥band`，四臂 apct 上限恒 < band 故实际未触发任何剔除）与收盘涨停（`chg≥band`）。
3. **"开盘即封板买不进"以收盘涨停代理**——日线近似无法区分开盘一字板与盘中封板；采用 C2b 同款 `chg≥band` 剔除（与基线完全同口径，保证公平对比）。
4. **卖出沿用 yang9_M 日线语义**（首 chg≥9% 兑现 / 封板次开 / 14 日强卖），未建模分时盘中成交价，按当日收盘/次日开盘价成交。
5. **本卡全部分数均为"日线近似的竞价战法"**，不等价于真实竞价数据回测；若未来获得真竞价数据（09:15-09:25）需重做。
