## §5 时间与市况结构（直说）

- **2019-2023 不成立**：真 IS 上主池任何买点×卖点组合的 exp 均 ≤ +1.14%，用户语义的"回调中买"更全部 ≤0。风口 zt≥50/80 是唯一稳定正收益（+1.4%/+3.1%），但那是"全市场批量涨停日的 β"不是战法本身。
- **2024 后吃 β**：OOS 全部转正（+2.8%~+12.6%），且按年看 2024（+14.4%）、2026（+16.2%）强、2025（+8.6%）弱——与市场行情正相关。
- **结论**：这套"首板→回调→大阳/涨停兑现"战法**在 2019-2023 震荡/熊市环境下不赚钱，盈利来源是 2024 后的趋势行情**。若人类预期"任何时候都能跑"，数据不支持。

## §6 诚实披露（沿用 v1 + 泄漏教训）

1. **幸存者偏差（最重）**：快照仅含现存续 2354 票，无退市股，结果系统性乐观（本项目已实证静态池牛市窗夸大 +16~32pp）。**OOS exp +4.9%（推荐）应再打折看待。**
2. **泄漏污染教训（本块新增）**：v1 因 `event_mask` 缺 `end`，全网格混入 2024-2026 数据，把 IS 选参从"几乎全负"洗成"普遍为正"（base +0.5% vs 真 −1.0%、yang9 +3.5% vs −0.8%）。**凡分段回测必须显式 `end` 上界 + 事件数自检（IS+OOS=全窗）。**
3. ST 不可识别（ST 5% 板不误入、但带宽失真）。
4. 行业风口用代理（全市场涨停家数/sentiment），未捕获板块结构。
5. qfq 方言：比值类信号幸存；绝对价位（首板开盘、MA 支撑）失真 → **E2 支撑买点受污染**，与真实 qfq 下表现可能不同。
6. 涨停价不可成交近似：买点当日收在涨停带宽判买不进剔除，盘中路径无法还原。
7. 样本：推荐组合 IS n=1555 / OOS n=815，均 >100 可信；风口 zt≥80 真 IS n=239 偏薄。

## §7 给 W2 的接口说明（结构不变，数值更新）

对任意 code+date 输出状态（按 `yang_rule.recommended`）：
1. **不在池**：非首板 / 前 7 日有涨停 / 未过三关（MA5vol≤MA60vol 或未创 20 日新高或未爆量）。
2. **首板确认**：`status="first_board_confirmed"`。
3. **回调第 k 日**：首板后第 k 交易日（k=1..10）。
4. **买点触发（E2 回调中）**：`|low-fb_open|/fb_open≤2% 且 vol<0.5×首板量` 且当日未封涨停 → `status="entry_triggered"`，`buy_at=close`。
5. **持有期目标（M 混合卖点）**：`chg≥9%` 日——未封涨停 → 当日收盘卖；封涨停 → 次日开盘卖。
6. **失效**：14 交易日无 ≥9% 大阳 → `expired_fallback`（收盘强卖）。
7. 对照 schema `recommended_rule`（E3 大阳确认买 + yang4_M / V2 二板）供 W2 板块信号选型，默认 off。
