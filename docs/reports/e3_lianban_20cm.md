## §4 换卡建议（recommended_rule_v2）

**判定**：10cm 最优组合均值（+2.370%）**略低于**混合版（+2.413%，−0.043pp）——**非"均值明显优于"**；但该差异**全部来自 20cm 的 123 个不可信样本（+4.386% 高均值）的拉动**。混合版 98% 样本本就是 10cm。

**结论：追加 `recommended_rule_v2`（10cm 限定版）**，理由是可信度而非均值：
1. **10cm 完全可信**：n=5588、IS +2.543% / OOS +2.211% 双正、8 年逐年正、winA~0.70
2. **20cm 完全不可信**：缩量最优组合 n=123<100（按年 7-36），其 +3.8~+4.7% 高均值是样本过小的噪声；20cm 全量打板虽 n=2696 且 +1.676% 高于 10cm，但外部证券时报反方"20cm 首板炸板率 62%"未能否证
3. **与已落地堵口一致**：tactics.py 已把 20cm 从候选剔除，规则卡应反映实际（`RULE_SOURCE` 指向 recommended_rule 时实现已堵 20cm）

`recommended_rule_v2` = V1 `recommended_rule` 深拷贝 + `board_scope: "10cm"` + `board_scope_desc`（60/00，排除 30/68/8/4/920）+ note 说明拆分结论。**仅追加该键**，JSON 级 diff 确认其余键零改动（哈希：原始 227491BC → 现 17D11A99）。

## §5 诚实披露

- **"10cm 明显优于混合版"不成立**（−0.04pp），故本报告换卡论据为"可信度 + 外部反方 + 堵口一致性"，非均值优势；该点已写进 v2.note，供人类下轮决策
- 20cm 全量打板（n=2696，+1.676%）是**本块唯一显示 20cm 可能正期望的网格格**（非缩量过滤），但样本仍偏小且未做外部对表（证券时报 62% 炸板率是反方）——**不建议据此单独落地 20cm**
