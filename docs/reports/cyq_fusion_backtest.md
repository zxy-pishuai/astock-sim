## §5 结论与证据强度

**null 结论（按预注册判据）**：8 个筹码融合臂均未过"双段不劣 + 至少一段 n≥300 的 +0.5pp/+2pp 增益"门槛，**不接 C3 接线**。

**证据强度诚实评估**：
1. **方向性提示（非结论）**：A1（winner≤60）在 OOS(2024-2026) 期望 +17.12%（n86，提升 +12.21pp）、胜率A +4.3pp、胜率B +0.65pp，方向与筹码战法直觉一致（低位获利盘票）；A2（winner≤80）同向但温和（n210）。IS(2019-2023) 提升仅 +0.2~0.4pp——**IS 增益小、OOS 增益大的不对称**，且 OOS 样本小，无法区分"真 alpha"与"2024-2026 市况+小样本运气"。
2. **为什么判 null 而不是阳性**：n86 的期望 17.12% 置信区间极宽（粗估 ±8~10pp），无法确认 ≥+0.5pp 统计上显著；判据 n≥300 门槛即为此设。诚实报 null，不为了"有料"放水。
3. **给 C3 的后续建议（只建议不接线）**：若想验证 A1，需①扩大买点样本（放宽 E2 触发条件或改 E1 盲买口径跑筹码分层）、②对 OOS 做分年/分情绪稳健性、③或等更多 2025-2026 数据积累。在此之前，**筹码过滤不进入接线**。
4. **其他臂**：A3/A4（集中度）IS 即劣于基线，无方向；A5/A6（峰位）OOS 劣于基线；A7（获利盘回落）方向最好但 n=1~2，纯噪音。
