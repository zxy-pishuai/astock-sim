## 二、验收发现的问题

1. **【系统性】判定符号/单位 bug 第三例**（P37 dd_gate、我 P41 后自查、本轮 P68 exit_pack 又出现
   "牛市损失 ≥ -2 恒真"）。三个独立 AI 在独立工具里犯同类错 → 根因是各工具手写判定逻辑。
   建议：抽公共 `tools/judge_kit.py`（预注册判定函数），所有扫描工具 import 使用。
2. **【冲突】INDEX_TIMING_BOARD_ONLY 双任务处置矛盾**：任务 C 置 True，P54 置回 False。
   当前生效 False。根因是 P43 的 +1.05pp 结论在不同数据锚点间翻转（C 组复测 -17~-23pp）。
   裁定建议：接线保留、开关保持 False，待 P46 快照口径积累 ≥3 个交易日稳定数据后复验。
3. **【待落地】P54 的 109 只排除清单建议**（含 sz399001 指数误入，需剔除后落地）；
   另 xdxr 表缺失导致 24 条除权误报无法复核。
4. **【认知修正·最高优先】P64 幸存者偏差量化**表明现行池回测存在系统性前视高估：
   所有对外收益表述应附 PIT 对照值；历史报告建议批量加"偏乐观"标注。
5. 【小】app.lock（服务 PID 锁）用途未文档化；predict.py 实际只覆盖 177/700 只
  （最新 bar 特征 NaN 剔除率高），ml_scores.json 的覆盖率应写入哨兵检查项。
