# D1 报告：全球市场→A股映射规则的"真实全史"复验

- 状态：**已完成**（2026-08-27）
- 工具：`tools/global_map_verify_full.py`；结果：`data/global_map_verify_full.json`
- 口径：完整继承 Phase39（`docs/reports/global_map_verify.md`），判定规则事先写死不改；
  本轮只修正数据源的真实性/完整性
- 结论先行：**没有任何一条映射规则达到"保留"门槛 → 前瞻台账候选 0 条（无新增）**。
  Phase39 的三条主要结论在真实全史数据下全部复现；「港股科技」利多的微弱正向力
  在新加入的 ±1% 变体上同样成立且更稳健，但超额仍远低于 1pp 门槛。

## 1. 背景与本轮修正点

Phase39 复验时外部序列存在两处妥协：

| 序列 | Phase39 当时 | Phase63 回补后（本轮实际使用） |
|---|---|---|
| VIX | CBOE 在线窗口仅 **2018-11 起**（1,992 根） | `global_kline` CBOE 官方全史 **9,258 根（1990-01-02 ~ 2026-08-25）** |
| WTI | 东财限流 → **降级新浪 USO 代理**（ETF 含展期损耗） | `global_kline` 东财 CL00Y 真实连续合约 **7,029 根（1999-01-04 ~ 2026-08-26）** |
| 纳指/恒科 | 腾讯 ifzq 分页 | 同源不变（已覆盖评估窗） |
| 英伟达 | 新浪美股日线全史+拆股修正 | 同源不变（本轮修正 2001 7:1 / 2021 4:1 / 2024 10:1 三次拆股） |
| USDCNH | 无可靠免费历史源 → 跳过 | **仍跳过**：全球/免费渠道依旧只有实时报价；`global_kline` USDCNH 仅 4 行增量（<30），日内 >0.3% 口径亦无法从日K还原 |

复验范围对应 `app/global_market.py` 现行全部映射规则：五条正式规则
（半导体链 / 港股科技±2% / 油气 / 全球避险 / 汇率）＋「港股科技±1%」变体
（Phase57 实验组首次回测）。

## 2. 方法与窗口边界（诚实声明）

继承 Phase39 不变的部分：外盘 d 收盘→t=d 后首个 A 股交易日（PIT）；R1=close_t/open_t−1，
R5=close_{t+4}/open_t−1；三组代理板块等权、逐日在场成员；无条件基线=全样本同口径；
保留门槛 **n≥30 且 R5 命中率≥55% 且方向超额≥1pp**；命中 50~55% 区间看 ±50%
阈值扰动决定"调阈值/下线"。

本轮新增的对齐纪律：移除 Phase39 的"2018-11 截断守卫"后，外盘历史（最早 1990/1999 起）
若不加限制会被二分查找"传送"到序列首个 A 股交易日，破坏 PIT 语义。因此加了
**14 个日历日的最大间隔守卫**（覆盖春节/国庆调休的最长真实休市，窗口内实测最大≈10 天）：
早于评估窗的历史日期自然不产生任何触发映射。守卫开关前后两次运行结论逐项一致，
说明它只剔除虚假对齐、不改变统计。

诚实边界：A 股全市场日线库内自 **2019 年**起才有截面（2018 及以前仅零星个票），
因此触发评估窗与 Phase39 相同（本轮 1,852 个有效日，2019-01-02~2026-08-20 为 R5
可用段）；"全史"修正的价值在于——VIX 早年的历史极端期（如 2008）不再缺席而是被
正确对齐纪律处理，WTI 从"ETF 近似收益"变为真实期货连续收益。评估窗本身受本地
数据库覆盖所限，无法向前延展，此为本轮最大局限。

## 4. 「港股科技±1%」变体专节：为什么仍未通过保留门槛

恒科指数 2020-07-27 基期以来的利多触发，按阈值分档的全景（R5 口径）：

| 触发阈值 | 触发数 n | R5 命中率 | R5 超额 |
|---|---|---|---|
| ±0.5% | 550 | 58.00% | +0.20pp |
| **±1%（本轮变体）** | **425** | **57.88%** | **+0.31pp** |
| ±1.5% | 333 | 57.36% | +0.22pp |
| ±2%（现行正式规则） | 253 | 57.71% | +0.26pp |
| ±3% | 130 | 57.69% | +0.48pp |

命中率在 0.5%~3% 全部五个档位稳定处于 57~58%、超额恒正——**信号存在性确凿**
（这正是 Phase39 建议、Phase57 落地前瞻实验组时押注的性质，本轮全史+真实数据予以确认）。
但它是一种温和的"科技成长跟涨 β"：每档超额都只有 +0.2~+0.5pp，不到 1pp 保留门槛的一半，
换算成期望值约等于每次触发多赚万几点、还要承担触发日方差。**"有信息"与"可交易"之间
隔着一个数量级**，这一区分正是事先写死双条件的用意。

处理：维持 Phase57 既定安排不动——「港股科技±1%」继续作为前瞻台账实验组用
**真实未来数据**积累（需 60 个触发日，预计 2026-11 月前后出首个判定），本轮回测
不支持把阈值改成别的档位，也不支持提前转正。
