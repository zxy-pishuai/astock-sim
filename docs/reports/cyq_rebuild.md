### 0.1 复权因子修正（qfq 方言下的均价峰位）
快照 kline 为前复权 qfq 价（实测 000001 复权比例随 t 变化：2024-08 c=1.088、2019-06 c=1.273）。三角峰=当日真实均价 `amount/volume`，需映射进 qfq 坐标系：
`f(t) = close_qfq(t)/close_real(t)`（新浪未复权 close），`avg_qfq = (amount/volume) × f(t)`。
经新浪真实 close 逐日修正后峰位落入正确价格带（P2 验证通过）。当 close_real 缺失时 f=1（近似，报告 §3 披露）。

### 0.2 换手率与覆盖率（全量实测）
- 主源：新浪 `stock_zh_a_daily`（东财不可达降级），全史 2019-01-01→2026-09-01，缓存 `data/cyq_turnover.parquet`
- 覆盖率：**2113 票 / 2423（87.2%）**；缺失 310 票全部为新浪无数据（退市/停牌老股，"No value to decode"），未生成 cache
- 全量计算：2423 票 668.8s（~11 分钟，3.62 票/s），0 失败；**补拉 23 票**（并行拉取 worker 残余 batch 未 flush 竞态，尾部 6887xx-6888xx 丢失→已补拉并 append，见 §6 自检）
- turnover_src 全量分布（3,5xx,xxx 行）：sina ~90%、missing ~10%（2018 年段 + 新浪无数据日）、listed5 0.3%；`self`（volume/outstanding_share 兜底）**未实际触发**——新浪 2019 起才提供流通股本，2018 年段连股本一并缺失，无法自算（兜底逻辑已实现但数据源特性限制，诚实披露）
- 2018 年段：新浪换手率仅 2019 起 → 2018 年有效换手率为 0（分布只衰减不叠加），`turnover_src='missing'` 标注；事件前 250 日窗口（2019 初事件需 2018 历史）受影响，已在 §3 披露

## §2 P2 内部一致性门（真实换手率）

### 2.1 方法
对抽样票（含银行/地产/通信等不同风格），用真实换手率重建后检验：
- `Pearson r(diff(winner_pct), chg)` 应显著为正（获利盘日变化与当日涨跌强相关）
- 暴跌 5% 分位 `dw` 均值应显著为负（获利盘骤降）、暴涨 5% 应显著为正、中段应≈0
- 指标范围：winner_pct∈[0,100]、conc90∈(0,1)、peak_density∈(0,1)（非退化）

## §3 已知失真清单（诚实披露）
1. **qfq 方言绝对价位失真**：库内 70.8% 票为"恒定比例放大"方言，所有指标已比值化（winner_pct/conc90/peak_dist_pct 等），**绝对峰位价格仅以"距现价 %"输出**（C2 禁用绝对价格）；
2. **2018 年段无换手率**（新浪仅 2019 起）：2018 年分布只衰减不叠加，`turnover_src='missing'`；2019 初事件的前 250 日窗口会受此影响；
3. **close_real 缺失时 f=1 近似**：少数无新浪数据的票复权因子修正失效（仅影响峰位定位，不影响比值指标）；
4. **退市/停牌票**：310 票新浪无数据（"No value to decode"）→ 无换手率 → 未生成 cache；此类票不在 C2 事件池（幸存者偏差已披露），影响可忽略；
5. **新股前 5 日豁免**：`turnover_src='listed5'`，指标 NaN；
6. **一字板**（有效换手率<0.1%）：当日只衰减不叠加，分布钝化——符合批文处理；
7. **ST 无法识别**：换手率/价格均正常计算，不做 ST 区分；
8. **三角分布假设**：日内筹码在[low,high]三角分布为理论假设，实际换手分布不可观测（C0 调研 §2 分歧项）；
9. **集中度 conc90 为 90% 成本宽度/中价**，qfq 方言下比值仍安全，但跨票可比性受各自复权基准影响。

## §4 给 C2 的使用说明
- 指标文件：`data/cyq_cache/{code}.parquet`，列 `date, winner_pct, conc90, peak_dist_pct, peak_density, dual_peak_gap, profit_trend5, turnover_src, seam_flag`
- 取样规则：**事件日/买点日 t 收盘口径**——取该票 date=t 行的 6 指标；需事件前历史时直接用全序列
- 字段语义（C2 回测判据候选）：
  - `winner_pct`：获利盘比例 0-100（现价下方筹码占比）
  - `conc90`：90% 成本集中度（越小越集中；<0.10 一般视为控盘密集区）
  - `peak_dist_pct`：最近主峰位距现价 %（负=峰在现价上方=套牢压力；正=峰在下方=支撑）
  - `peak_density`：峰密集度（峰顶筹码占比，越大越集中）
  - `dual_peak_gap`：上峰-下峰间距 %（双峰结构、压力/支撑带）
  - `profit_trend5`：获利盘 5 日变化（吸筹/出货信号）
- `seam_flag=1` 的行是除权断层日（分布不叠加只衰减），C2 判据应跳过或特殊处理该日
- 事件池对齐：W1R 真 IS 主池（`event_mask(pre=7,brk=20,vol='OR',trend=True,start=2019-01-01,end=2023-12-31)`，5721 事件）+ V1 连板首板（`tmp/v1/events.pkl`）
