## §0 判据原文（预注册，先抄后跑，跑完不改）

照抄 C2b 提示词第一节，补执行记录（§0a/§0b）。

> **分层**：对 4 个指标（winner_pct、conc90、peak_dist_pct、peak_density）各做 IS/OOS 内五分位（Q1..Q5，按 IS 分位切点映射到 OOS，防泄漏），每档出 n/期望/胜率/MAE。
> **单调性判过（进板块的门槛）**：某指标满足——
> a) IS 与 OOS 的 Q5−Q1 期望差**同号**且 OOS 段 |Q5−Q1|≥2pp；
> b) 分位序与期望的 Spearman ρ 在 IS、OOS **同号**且 OOS |ρ|≥0.5；
> c) OOS 分年（2024/2025/2026）方向不反转（至少 2/3 年同向且无一年反向>1pp）；
> d) 每档 OOS n≥500（盲买宇宙 ~3700/5≈740，天然满足）。
> **判不过**：任一条件不满足即 null——**筹码指标在本体系盖棺定论**，报告写明"分位信息无可利用的横截面排序力"，后续不再重开（除非数据量翻倍）。
> 多重比较：4 指标 × 双段，报告须列全部 8 组，禁止只报过者。

**§0a 盲买口径**：事件 t 的次一交易日（t+1）**开盘价买入**（不复用 E2 触发条件，故样本数远大于 C2）；t+1 当日收在涨停带宽（买不进）剔除；卖出沿用 yang9_M（`_sell_path`：持有期首个 chg≥0.09 即卖，封板次日开盘卖，否则 14 日强卖）；扣费 `(1-SELL_COST)/(1+BUY_COST)*ret-1`（与 W1R 一致）。
**§0b 筹码采样**：主采样=买点日（t+1）收盘行指标；事件日（t）采样仅作对照列（§4）。seam_flag=1 采样日剔除；买点日无 cache 行→剔除计数。
**§0c 分段沿用 C2 §0a 已证之日切**：IS=2019-01-01..2023-12-31、OOS=2024-01-01..2026-08-31。

## §4 采样时点对照（买点日 vs 事件日结论是否一致）

同一批盲买样本（ret 相同），分别用买点日（t+1）与事件日（t）收盘指标分层：

| 指标 | 口径 | IS Δ / ρ | OOS Δ / ρ | 两口径方向一致？ |
|---|---|---|---|---|
| winner_pct | buy(t+1) | +0.024 / +0.40 | +0.053 / +0.30 | ✗ **相反** |
| winner_pct | ev(t) | −0.021 / −0.70 | −0.016 / −0.50 | |
| conc90 | buy(t+1) | +0.024 / +0.90 | +0.029 / +0.60 | ✓ 一致 |
| conc90 | ev(t) | +0.024 / +1.00 | +0.028 / +0.60 | |
| peak_dist_pct | buy(t+1) | −0.017 / −0.60 | +0.020 / +0.30 | ✗ 均不稳定 |
| peak_dist_pct | ev(t) | +0.023 / +0.90 | +0.008 / −0.20 | |
| peak_density | buy(t+1) | +0.0001 / −0.10 | −0.083 / −0.70 | ✗ buy 反号 |
| peak_density | ev(t) | −0.006 / −0.70 | −0.019 / −0.50 | ✓（负向，但 buy 口径 IS≈0） |

**结论**：
1. **conc90 是唯一双口径方向一致的指标**——买点日与事件日采样的排序方向、强度（IS ρ 0.9-1.0、OOS 0.6）几乎相同，说明其横截面信息对采样时点稳健。这是 C2b 全部结果中最值得留观的信号。
2. **winner_pct 两口径方向相反**（buy 口径"高获利盘优"、ev 口径"低获利盘优"）——首板涨停日（t）winner 普遍极高（分布极端右偏，ev 口径 Q5 达 2202 样本），分层方向被采样日反转，**不可靠**。
3. peak_dist/peak_density 双口径均不稳定 → 无排序力。
4. 综上，即使换采样口径，也无指标通过全部判据——**null 判定稳健**。

## §6 自检记录

1. **随机 2 指标 × 20 事件手工复算**：winner_pct / peak_dist_pct 各抽 20 个 OOS 样本，独立重算指标值 → quintile（np.digitize(IS 切点)）与跑批分档一致，且该档 exp 命中（存 `selfcheck.manual_20`）；
2. **切点来自 IS 的证明**：`selfcheck.*.is_cuts` 记录各指标 IS 切点，OOS 分层一律用该切点（`np.digitize(vals, cuts)`），无 OOS 重算切点（防泄漏）；
3. **n 守恒**：每指标每段 Q1..Q5 n 之和 == 总样本 n（`n_ok_IS/OOS` 全 True）；
4. **盲买样本剔除明细**：zt_open / no_cache / no_row / seam 逐类计数（IS/OOS），未静默丢弃；
5. **双口径对照**：§4 买点日 vs 事件日用同一 ret 集合，仅指标采样日不同，结论对比公平。
