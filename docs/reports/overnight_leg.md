- **块**：R1｜隔夜腿策略回测（研究型，零落地）
- **时间**：2026-08-31
- **数据钉点**：`data/snapshots/2026-08-31/market.db`（只读 URI 打开，禁写活库）
- **背景**：`docs/reports/ml_short_label.md`（B1）发现预测力集中于隔夜腿（label_c2o IC=0.150、top 分位 +0.243%/日），扣费后约打平，当时结论"可作小仓位倾斜"但无人落地验证。本块独立设计并回测隔夜策略以验证该结论。

## 0. 预注册判据（写死，落盘后不得修改）

策略形态（任务给定，不改变）：**T 收盘买入（当日 close）→ T+1 开盘卖出（次日 open）**，A股 T+1 天然满足，隔夜单腿持有。

**预注册判定（依据最终回测净收益，滑点中间档 0.002 为主判据）：**
- **C1**：四窗中扣费后净收益 > 0 的窗数 ≥ 3/4；
- **C2**：牛市窗（2025-08-18~2026-08-18）扣费后净收益 > 0，且 ≥ 0.6 × 同池等权持有基线净收益（基线 > 0 时；若基线 ≤ 0，则牛市窗净收益 > 0 即满足）；
- **结论规则**：C1 且 C2 → 建议 10-20% 小仓位并入现行持仓；否则**存档了结**（不落地）。
- 附：滑点三档敏感性 0.001/0.002/0.003 用于稳健性旁证（中间档符号不翻转则结论稳健；若翻转，仍以中间档为准并在结论注明）。

**四窗**（沿用项目既有约定，同 tools/backtest_dd_gate_v2.py）：
| 窗 | 起 | 止 |
|----|----|----|
| 2019-20 | 2019-01-01 | 2020-12-31 |
| 2021-22 | 2021-01-01 | 2022-12-31 |
| 2023-24 | 2023-01-01 | 2024-12-31 |

**股票池**：`data/bt_pool.json` 前 500 − `app/config.py` 的 `DATA_EXCLUDE_CODES`（沿用既有回测配方，实测 458 只）。

## 1. 策略设计（预注册）

### 1.1 选股代理构造（规则化，与 c2o 方向自洽）

选股代理不可用 `ml_pred`（历史仅 8 月中旬起，不足四窗回测）。规则代理设计过程（实证驱动，报告写明）：

- **初试「动量+量能+涨幅带」组合**（任务示例方向）：涨幅带 [2%,7%] + 动量 momentum5 + 量能 vol_ratio，四窗隔夜 IC 实测为负（-0.069~-0.005），**方向与 c2o 相反**——A股强势股隔夜反转，涨幅带 2-7% 组隔夜 -0.224%/d（2019-20）。不符合"与 c2o 方向逻辑自洽"要求，**弃用**。
- **因子扫描**（快照全池，见 §附A）：单因子对隔夜收益（close→next open）的 IC 多为负或近零；复合条件中仅**缩量/低波**类方向为正或抗跌（2019-20 低波缩量 +0.068%/d、缩量上涨 +0.046%/d、平盘缩量 +0.027%/d；2023-24 各条件趋近 0）。
- **最终规则代理（预注册）**：
  - 温和涨幅带：`-0.01 ≤ ret1 ≤ 0.02`（ret1 = 当日涨幅；避开强势反转与大跌）
  - 低波：`vol10` = 近 10 日日收益总体标准差（低波优先）
  - 缩量：`vol_ratio` = `volume[T] / mean(volume[T-5..T-1])`（缩量优先）
  - 综合分：`score = 0.5*(1-pct_rank(vol10)) + 0.5*(1-pct_rank(vol_ratio))`，在带内股票截面排名
  - 每日选 `top-N`，`N = clamp(ceil(0.10 × 带内数), 10, 30)`
  - 逻辑自洽说明：c2o 假设为"选中股票次日开盘向上（正隔夜）"；A股无条件隔夜为负漂移（实测 -0.04%~-0.07%/d），负漂移集中在高关注/高波动/强势股，而低波缩量的安静股负漂移最小甚至转正——本规则选取"安静低关注"股，方向与 c2o 假设一致（抗负漂移、趋正隔夜）。

### 1.2 费用模型（预注册，app/config.py 现行档）

- 佣金 `0.00025`（万2.5）双边；最低 5 元假设单票名义 ≥ 2 万元不触发（研究口径，注明）；
- 印花税 `0.0005` 仅卖出；
- 过户费 `0.00001` 仅沪市（6 开头）双边；
- 滑点三档敏感性 `S = 0.001/0.002/0.003`：**收盘买入滑点 = S**；**次日开盘卖出滑点 = min(0.003, S+0.001)**（开盘卖出按更差档）；双向滑点合计 0.003/0.005/0.006。
- 每交易日满仓等权持有 N 只，隔夜进出各一次 → 日频成本约 `0.102% + (S + min(0.003,S+0.001))`。

### 1.3 基线

同池等权**买入持有**：窗首日收盘买入 → 窗末日收盘卖出，中途不调仓（取首末日均有数据的池内股票）。

## 2. 回测结果

预注册规则（§1.1 最终代理）四窗回测，快照 `data/snapshots/2026-08-31/market.db` 只读，池 458 只（bt_pool top500 − excludes）：

| 窗 | 交易日 | 毛收益 gross | 净 S=0.001 | 净 S=0.002 | 净 S=0.003 | 持有基线 BH | 规则隔夜IC | 净>0 天数占比 |
|----|--------|--------------|------------|------------|------------|-------------|------------|---------------|
| 2019-20 | 487 | −10.25% | −87.3% | −95.2% | −97.1% | +57.5% | −0.015 | 6.4% |
| 2021-22 | 485 | −7.05% | −86.8% | −95.0% | −96.9% | +5.6% | +0.020 | 2.7% |
| 2023-24 | 483 | −1.21% | −85.8% | −94.6% | −96.7% | +23.4% | −0.006 | 3.3% |
| 牛市 | 243 | −7.25% | −65.1% | −78.5% | −83.2% | +85.4% | −0.015 | 3.7% |

- 规则代理对隔夜收益的 Spearman IC 四窗均 ≈ 0（−0.015 / +0.020 / −0.006 / −0.015），**无稳健正向预测力**；
- 毛收益四窗全部为负或近零（−10.25% / −7.05% / −1.21% / −7.25%），即"低波+缩量+温和带"选出的安静股隔夜仍略为负漂移，无法转正；
- 日频隔夜进出带来约 0.10% 费用 + 0.3%~0.6% 滑点（S+min(0.003,S+0.001)）的**日频成本**，在 240~487 个交易日后复利吞噬一切收益（net 三档均 −65%~−97%）。

## 3. 判定与结论

**按 §0 预注册判据：**
- **C1（≥3/4 窗净收益>0）**：净收益 > 0 窗数 = **0/4** → **不满足**；
- **C2（牛市窗净收益>0 且 ≥0.6×基线）**：牛市窗 net = −65.1%~−83.2%（<0）→ **不满足**；
- **结论：存档了结，不落地**（不并入小仓位）。

**关键发现：**
1. **简单规则无法复刻 ML 的 c2o 信号**。任务示例方向的「动量+量能+涨幅带」组合隔夜 IC 为负（方向与 c2o 相反，A股强势股隔夜反转）；改选实证方向最优的「低波+缩量+温和带」后 IC 仍 ≈ 0，毛收益仍非正。c2o top 分位 +0.243%/日 需要 alpha158 的 ML 模型特征组合，非透明规则可达。
2. **隔夜策略的日频成本结构使其天然难盈利**：每日一买一卖 ≈ 0.1% 费用 + 滑点，即便毛收益 +0.2%/日也仅打平。ml_short_label 估计"扣 0.10~0.20% 后约打平"与此一致；本回测按三档滑点（开盘卖更差档）后，**在毛收益非正的规则代理下净收益深负**。
3. **对"可作小仓位倾斜"结论的修正**：该结论成立的前提是**仅对 ml_pred 高分股**（ML 信号本身）做隔夜倾斜叠加，且需重新核验 ml_pred 扣费后的实际净收益；**不能**推广为任意简单规则的独立隔夜策略。建议后续仅当 ml_pred 历史累积足够（≥ 数个完整窗口）时，用 ML 信号本身重跑本四窗口径验证。
4. 稳健性：三档滑点符号一致（全负），结论对滑点口径稳健；即便采用更轻的"整轮滑点=S"口径（日成本约 0.2~0.4%），毛收益非正下净收益仍深负，判定不变。

## 附A：因子扫描证据（设计依据）

快照全池（458 只）无条件隔夜收益（close→next open）实测：2019-20 −0.077%/d、2021-22 −0.074%/d、2023-24 −0.039%/d、牛市 −0.025%/d（A股隔夜负漂移）。单因子/复合条件对隔夜收益方向（2019-20 / 2023-24 两窗抽样）：

- 单因子 Spearman IC：ret1 −0.020/+0.009、mom5 −0.052/−0.016、mom10 −0.037/−0.029、vol_ratio −0.069/−0.033 → **动量/量能方向为负或近零**；
- 条件均值（%/d）：涨幅带 2-7% −0.224/−0.052（强势反转）、跌幅带 −7~−2% −0.133/−0.119、平盘 −0.027/−0.062；
- 缩量/低波类：缩量上涨(vr<0.8,ret1>0) +0.046/−0.005、平盘缩量 +0.027/−0.035、低波缩量(vol10<0.015,vr<0.8) **+0.068/+0.002**、微跌缩量 +0.045/−0.033；
- 结论：仅缩量/低波类在 2019-20 为正且 2023-24 趋零（不反转），是唯一方向自洽的透明规则族；据此预注册 §1.1 最终代理（取方向最优且跨窗不反转者）。
