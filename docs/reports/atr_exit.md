**结论（数据所指，直说）**：三臂 IS 段期望全部归零（+0.02~0.08% vs 基线 +2.56%），
即便 OOS 段 T1 微优也不足以救回——**ATR 跟踪止损对 A1 打板体系无增益**。机理与 V1
"打板赚的是隔夜高开溢价"互相印证且更严苛：**连波动率归一化保护下的延长持有，在
IS 段也把 +2.5% 的隔夜溢价耗成 0**。现行固定阈值（次日开盘卖）维持现状，本报告按
null 归档，不据此调任何阈值。§0a.3 声明：T vs 基线的差异含持有期/风险暴露因素，
非纯退出规则差异，不得解读为"ATR 退出更差"的强结论（它是"延长持有在打板体系
不成立"的证据）。

## §7 诚实披露

1. **幸存者偏差**：events.pkl 仅含现存续 2,355 票（2026-09-02 快照），无退市股；
   绝对收益系统性乐观，双臂比较受同样偏差影响（结构相对可比）。
2. **对照纯度**（§0a.3）：T 臂持有期 1→20 日，风险暴露本质不同；分年对比已尽量缓解。
3. **ATR 静态口径**：事件日 ATR14 持有期固定；动态 ATR（每日重算）未测，如要测属
   新增臂，仅作建议单。
4. **封板顺延近似**：涨停/跌停收盘日卖单顺延至首个非封板日开盘卖（engine 语义简化）；
   未建模开盘即封死等盘中细节。
5. **成交现实性**：基线打板"视为以涨停价成交"，真实排队不一定买得到（V1 §7 同款
   警示，额外成本容忍上限约 +1%）。
