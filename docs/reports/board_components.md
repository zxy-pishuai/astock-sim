## 3. 关键发现

1. **动量四档呈清晰的单调分层**：极强(+25)>很强(+20)>较强(+15)>启动(+10)，
   胜率 53.8%/50.6%/44.5%/45.5%、平均收益 +0.38%/+0.50%/-0.07%/-0.32%。
   **高档位有效、低两档是净拖累**——与 Phase33 把动量下限提到 8.0 的方向互相印证；
   本次证据进一步指向"启动档(+10，7~8.5% 涨幅)应降权或剔除"
   （n=336、-26,643 元，为最大单一亏损源）。
2. **放量扫板(+15) 是第二大亏损源**（-22,836，胜率 47.2%）且四窗方向不稳；
   其正面变体"温和放量(+10)"却是全场唯一四窗方向一致的正贡献成分——
   同一量比家族内部严重分化，提示"扫板追高"与"温和放量"应区别对待。
3. **振幅过大(-10) 是反向指标**：被它惩罚的回合反而小幅正贡献——振幅大在打板语境里
   未必是坏信号，现有减分依据不足。
4. 首板优先(+20) 覆盖 97% 回合（n=980），胜率 48.2% 略低于五成但总盈亏为正：
   它更像"策略本体"而非独立因子，单独降权意义不大。

## 4. seal_quality_bonus 切片（P17 建成后首次被度量）

**回测量化为零——机制性事实**：引擎 `_signals_on` 构造的 quote 不含 `code`，
`seal_quality_bonus(code, quote)` 在回测路径恒返回 (0, [])（其数据源 limitup 涨停池
也是实时接口，历史无法回放）。因此：
- 本次无法给出其历史贡献的证据，既不能证明有效也不能证明无效；
- 若要真正度量，需要①引擎把 code 传入 quote 并接历史涨停池快照，或②用实盘
  audit.jsonl 的信号-成交记录做事后归因——两者都超出本阶段"零代码修改"边界。

## 5. 建议清单汇总（只给证据，未改任何分值）

- **建议保留**：温和放量(+10)
