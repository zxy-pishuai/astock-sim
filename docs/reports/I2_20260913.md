## §2 验收判据逐条结论

### 判据 1：grep 无散落加分 —— **通过**
```
rg -n 'score \+= 10|score \+= 5|_b\["score"\] \+=|_score_one\(.*ctx' app\trader.py app\engine.py
→ app\trader.py:1290  def _score_one(self, code, quote, ctx=None):   （新签名，非加分）
→ app\trader.py:1432 / 1438  score += 10; signals.append("大盘强势(+10)")
```
- `trader.py:1432/1438` 属 **`_auction_round`（竞价打板公示）** 战法路径（非 `scan_once` score 策略评分），其评分体系是打板系，不属于 I2 统一范围（任务书任务 2 范围为 `trader.py:921-962` 即 scan_once 评分段）。已在报告说明，不并入 `score_final`。
- `rg "score_stock\(" app\trader.py app\engine.py` → **0 处**（全部收敛到 `score_final`）。

### 判据 2：一致性（parity）—— **通过**
`py -3.13 tools/test_i2_parity.py`（20 只 × 5 个历史日 = 95 个有效样本）：
| 检查项 | 结果 |
|---|---|
| 统一输入 parity（同 klines/quote/code/name/as_of/ctx，trader 形态 vs engine 形态） | **95/95 相同** |

| breakdown 结构（各项分值之和 == 总分） | 一致 |
| trader 旧加分复刻（旧三处加分逻辑 vs `score_final(ctx)` 逐位） | **PASS** |
→ 证明 `score_final` 是纯函数、单一事实来源，实盘/回测调用形态无路径分裂；`ctx=None` 时与旧回测逐位一致（同时支撑判据 4）。

### 判据 3：三臂对照 —— **完成（量化差异显著）**
窗口 2026-06-01~08-31（65 交易日，快照库 2026-09-02，主板价格 5-150 非涨跌停宇宙），threshold=60，T+1 开盘买、持 5 交易日收盘卖，双边成本 0.29%：

| 臂 | 口径 | 笔数 | 胜率 | 单笔平均净收益 | 简单合计 |
|---|---|---|---|---|---|
| A | 旧实盘：prescreen 粗筛 + ctx 加分（focus/板块/龙头）+ 资金面除外 | 361 | 43.77% | **-0.622%** | -224.7% |
| B | 旧回测：全候选 + 无加分（= 现 engine 默认） | 412 | 46.60% | **+0.021%** | +8.7% |
| C | 新统一：prescreen + ctx 加分（= `SCORING_UNIFIED=True`） | 361 | 43.77% | **-0.622%** | -224.7% |

- **A vs B 每日选股 Jaccard = 0.550**（65 信号日）——同一 threshold 作用在两个不同分数定义+两个不同候选集上，选股重合度仅 55%，**这就是 P1-F 回测落差的直接证据**（回测口径与实盘口径选出的股票过半不同）。
- **A vs C = 1.000**（64 信号日）：统一入口的同一性自证——C 与 A 同一评分函数同一 ctx，结果必然一致，反证收敛无实现分叉。
- 反向洞察：该窗口内**实盘口径（粗筛+加分）表现差于回测口径**（-0.62%/笔 vs +0.02%/笔）——回测结果比实盘"乐观"并非回测虚高，而是**回测根本没跑实盘的加分+粗筛逻辑**；实盘口径的板块/自选加分在该窗口反而拖累选股。此结论可直接喂给 C2 归因表。

## §5 已知局限（如实披露）
1. **focus（自选）无历史版本**：`engine._bt_ctx` 用当前 `watchlist` 静态近似——回测统一口径下自选加分用的是"今天的自选"；若需要真正的历史自选，需补自选变更审计（不在本单范围）。

3. **board/twothirty 独立战法未并入**（见 §0 裁决）。
4. 三臂窗口仅 2026-06~08 三个月（快照库覆盖上限），结论为该窗口实证，不外推全年。
