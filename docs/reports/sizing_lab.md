## 1. 方法与工具

### 1.1 仓位语义读码证据（app/engine.py，2026-09-01 读码）

- **L124**：`self.portfolio_method = p.get("portfolio_method", C.PORTFOLIO_METHOD)`
  → params 不传时取 config 默认 **`PORTFOLIO_METHOD = "risk_parity"`**（config L23）。
- **L646**：`pos_cash = self.cash * self.pos_pct` → **cash × position_pct**（**非 equity**）。
- **L684-689**：`w = self.portfolio_weights.get(s["code"])` → 有组合权重时
  `w_cap = min(1.0, w, C.RISK_SINGLE_STOCK_PCT*0.95)`；`pos_cash = self.cash * min(w_cap, self.pos_pct)`。
- **L648-661**：`portfolio_method != "equal"` 时用 `portfolio.compute_weights(...)`（risk_parity/hrp/vol_target）
  计算 `self.portfolio_weights`；**L662-663** 买入循环 `for s in signals[:slots]`，`slots = max_pos − used`。
- 结论：S0 即"固定参数 + risk_parity 权重 + 0.30 单仓现金上限"的现行行为；S1/S2/S3 通过
  **monkey-patch `portfolio.compute_weights`**（method 字符串 `w3_s1/w3_s2/w3_s3`）注入 ATR 权重，
  **不改 engine 任何一行**（运行时 hook，工具文件内解决）。

### 1.2 ATR 计算（PIT，纯标准库）

- 每格运行前，worker 从冻结快照只读加载池内各 code 的日K（open/high/low/close），
  预计算 `ATR14` 序列（TR = max(high−low, |high−prev_close|, |low−prev_close|)，14 日均值）
  与 `{code: {close(3位): date}}` 倒查表；monkey-patch 的 `compute_weights` 收到
  `closes_by_code`（截止信号日 prev_date 的收盘序列）后，用末收盘查日期 → 取该日 ATR14。
- `atr_daily = ATR14(prev_date) / close(prev_date)`；ATR 序列与倒查表均来自**同一快照**，
  与引擎 `_load_data` 读同一批行（浮点值同源，round 3 位匹配）。

### 1.3 指标定义（每格）

- `total_return` / `max_drawdown` / `sharpe`：引擎 `_metrics()` 原生。
- `daily_vol`：`std(equity 日收益率)`（引擎 `_metrics` 同口径）。
- `turnover`：`(Σ买入额 + Σ卖出额)/2 / 平均日权益`（窗口内累计换手率，全仓约 =1 为满换手一轮）。
- `stop_count`：卖出 trades 中 reason 含"止损"的笔数。
- `cash_mean`：`mean(equity[].cash)`。

### 1.4 工具

`tools/sizing_lab.py`（骨架照抄 R1 `tools/act12_t4_pit.py`：ProcessPool workers、幂等续跑、
逐格增量落盘、OUT 路径断言；策略层换血为 base_score + sizing 变体）。16 格任务 =
`{s0,s1,s2,s3} × {2019-20,2021-22,2023-24,牛市}`，全 PIT。

### 判定解读（必须带此限定）
- **本质是"风险削减"而非"选股增益"**：base_score 为净亏损策略（每窗 -11% 至 -57%）。S1/S2 通过降低暴露（单票权重 0.08-0.17 / 0.10-0.20 vs 0.30）同时削减损失与回撤——**降仓在负 alpha 上同时改善了收益与 MDD**。这与"vol-target 创造 alpha"不同。
- **结论不违反预注册**：判据设计即"MDD 改善 ≥5pp 且收益损失 ≤3pp"，S1/S2 远超达标；故结论为**值得接线**（而非任务书另一分支"仓位层救不了选股层"）。
- 接线建议（零落地，仅供决策）：若实盘沿用 base_score，S1（vol-target）最优先（MDD 12-28pp 改善、收益 -18~-26pp 改善、牛市 -4.3pp 改善），S2 次之（机制更贴近"单笔风险预算"，MDD 10-19pp 改善）；但需注意这是"少亏"而非"转正"，不应误读为策略转优。

## 5. 结论与资源占用注记

### 5.1 结论（零落地声明）
- **研究结论：值得接线**（S1 最优先）。量化结果：vol-target / ATR 风险预算在 base_score 上把四窗 MDD 平均改善 **+21.6pp（S1）/ +14.1pp（S2）**，且收益四窗平均改善 **+17.8pp（S1）/ +11.3pp（S2）**，牛市窗不劣化。
