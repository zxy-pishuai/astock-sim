## 1. 方法与口径

### 1.1 时序对齐（PIT）
外盘 T 日收盘全部发生在 A 股下一交易日开盘之前（美股/原油/VIX 收于北京时间次日凌晨，
港股 16:00 收），统一取 `t = 外盘日期 d 之后的首个 A 股交易日`，只用 t 开盘前已知信息。

### 1.2 收益口径（规则与基线同口径）
- R1 = close_t / open_t − 1（t 开盘入场，当日收盘）
- R5 = close_{t+4} / open_t − 1（t 开盘入场持有 5 个交易日）
- 无条件基线（1850 个交易日）：R1 = **+0.159%**，R5 = **+0.562%**
- 方向命中：利多=R>0 占比；利空=R<0 占比；同一 t 多次触发去重

## 4. 总结论（诚实版）

1. **五条映射提示中没有一条具备可交易的短期预测力**：全部未达"保留"门槛
   （超额普遍 <0.5pp，远低于 1pp 门槛）。
2. 唯一值得进一步研究的是**港股科技利多方向的微弱正向信息**（三个阈值档命中率
   均为 57~58% 且超额恒正）——若 Phase29 前瞻记账想纳入，建议先把触发阈值降到
   ±1% 再做前瞻验证；当前 ±2% 的设定恰好把最有效的温和触发过滤掉了。
3. "利空触发"全线无方向信息甚至反向（利空次日反弹），提示这些规则的文案
   （"情绪偏弱"类）对短线择时有误导性。
4. 局限声明：半导体代理仅 4 只、WTI 用 USO 代理、HSTECH 自 2020-07 才有序列、
   股票池存在生存者偏差；这些都不影响"现有规则无显著预测力"的方向性结论。
