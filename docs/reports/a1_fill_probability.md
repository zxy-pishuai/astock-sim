# C4｜A1 可成交性建模：涨停价排队成交概率（2026-09-13）

## §0 判据预注册（先于结果落盘；脚本 `tools/bt_a1_fill_prob.py` 头部同文，跑完未改）
1. **覆盖率判据**：min5 对 A1 历史信号（10cm 首板缩量非一字，n=5588）覆盖率 = 信号(code,date) 落在 `kline_min5` 覆盖内占比。若 <5% → 声明"min5 无法直接支撑历史信号封板概率重建"，改用 limit_pool（2026-08-15~09-11 近月涨停池）封板行为分布 + M2 先验（`live_fill_calibration.json`：sealed_le_1030=0.3 / sealed_gt_1030=0.6 / broken=1.0，先验设定非实测）做代理口径。
2. **三档情景**：S1 理想 P=1（现状基线，V1/atr_exit 已含 QUEUE=0.001 排队惩罚）；S2 概率加权（封板行为分布 × M2 结构）；S3 保守（仅 zbc≥1 炸过板的成交，未炸一律买不到）。
3. **判定**：S2（limit_pool 口径）折扣后 OOS 期望 ≤0 → 如实报 null + 给替代执行臂；>0 → 报折扣后数值 + edge 保留比例 + 敏感性区间（M2 先验 ±0.15）。
4. **校准判据**：实盘 board 成交（live_fill_calibration + account.json board 类）n<30 → 声明"样本不足，模型未实证校准"。
5. **覆盖口径**：min5 仅 2025-08-18 起 515 只数字代码票（60/00 共 326）；A1 窗口 2019-01-02~2026-08-21；limit_pool.date 为交易日+1 标签（周末重复打标），payload 归属前一交易日。

## §2 A1 组合板型分布（日K 可重建的成交代理）
| 板型 | n | 占比 |
|---|---|---|
| open==close（开盘即封，T字/一字类） | 119 | **2.1%** |
| open<close（盘中拉板，换手类） | 5469 | 97.9% |

A1 组合已剔一字（`board_type != '一字'`），组合内 97.9% 是盘中拉板——**板上都有盘中成交窗口**，打板成交概率不为 0 的结构性证据。但"盘中拉板"不保证买到：若 09:35 封死到收盘（fbt 早、zbc=0），排队同样可能买不到 → 仅靠日K 板型无法区分，需封板行为分布（§3）。

## §5 校准（如实报告：不可行）
- `live_fill_calibration.json` board 成交仅 **2 条**（2026-08-17 新洁能/飞龙股份，均"未触板→M2 假设 100% 成交"类），且当时未触板（炸板/未封）。
- `account.json` 35 条成交**无 board 类**（全 score 策略）。
- **校准样本 n=2 <30 → 模型未实证校准**；M2 先验（0.3/0.6/1.0）保持"先验设定，非实测"状态。无法回答"模型是否系统性乐观"——这是本块最大缺口，敏感性区间已覆盖其不确定性。

## §6 判定与对 C2 的建议
**判定：edge 未归零，不报 null。** 主口径 S2 折扣后 OOS 期望 **+1.69%**（每信号期望），最保守 S3 仍有 **+1.12%**，均显著为正（对应年化口径 ≈ +1.1%~+1.7%，8 年全正结构不变）。
- 对 C2 资金再分配：A1 的可成交性折扣约 **24%（S2）~50%（S3）**，但**正期望在真实成交下仍成立**；建议 C2 按 S2 折扣（保留 76%）做资金分配，并保留"排队失败资金闲置"的 0 收益假设。
- **与 atr_exit/V1 的 +1% 容忍上限对表**：+0.1% 排队惩罚已在基线；本块额外量化的是"买不到"本身——S2 相当于每笔期望再损失 ~0.53pp（OOS 2.21→1.69），S3 损失 ~1.10pp，**均在 ±1% 容忍上限的边界内（S3 略超）**，与 V1 §7"额外成本容忍上限约 +1%"的披露一致（0.53pp < 1% < 1.10pp 之保守端）。

## §7 替代执行对照臂
- **A2 次日开盘追**（V1 网格，OOS 负期望 −0.55%~−1.22%，T2 报告引用）→ 已证不可行，非替代。
- **开板买入**（不排队，等盘中炸板/开板以涨停价附近成交）：历史不可回测（无分钟数据覆盖），且与"打板"逻辑重叠（S3 即开板才买口径，OOS +1.12%）→ **S3 即为该臂的近似代理**，正期望但样本内 edge 最薄。
- 结论：无更好的替代执行方式；打板本身在 S2/S3 口径下仍为正。

## §8 诚实披露
1. **min5 覆盖率 0.18%（10/5588）**——任务书预期的核心限制已实证；覆盖子样本 n=10 不可信，未用其结论。
2. **limit_pool 近月代表历史**：2026-08-15~09-11 约 20 交易日的封板行为代表 8 年 A1 信号，若近月打板生态（炸板率/封板时刻分布）与历史显著不同，S2/S3 成交率偏移；敏感性已给区间。
3. **M2 先验未校准**（n=2）；0.3/0.5/0.6/1.0 是社区/项目内先验，非实测。
4. **口径 B 为"整体成交率 × 原期望"的线性折扣**，未建模"买不到的票恰是次日收益更高的强票"（fbt 早、封单强 → 溢价可能更高）——若成立，真实折扣比 S2 更深（向 S3 端偏移）；反向偏差也可能存在。**无法用现有数据分辨，列为已知缺口**。
5. **样本偏**：limit_pool 含一字（S2_all 0.740 < S2_adj 0.786），A1 已剔一字 → 主口径取 lbc=1 与适配两值，差异 0.023。
6. 覆盖子样本仅 OOS 尾 4 天，**IS 段（2019-2023）成交概率完全无数据支撑**，IS 折扣数字（§4）全部来自近月代理外推。
