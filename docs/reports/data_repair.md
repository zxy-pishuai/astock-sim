## 任务2：美元指数 DINIW 历史回补

### 源探测记录（逐个实测）

| 候选源 | 实测结果 |
|---|---|
| 东财 push2his secid=100.UDI | ✅ 可用但**间歇性掐断连接**：需带 `Referer: https://quote.eastmoney.com/` 且必须用 `beg/end` 参数（用 `lmt` 返回空 klines）；多次触发限流。恢复后实测返回 name="美元指数"、7,135 行（1999-01-04~2026-08-24）。已列为备选 |
| 东财 push2his secid=100.DINIW | 连接同样不稳；未及返回数据（UDI 已满足需求） |
| 腾讯 fqkline usUDI | ⚠ HTTP 200 但**是错误标的**："股息收益ETF-USCF (UDI.AM)"，非美元指数，仅存证不可用 |
| 腾讯 fqkline usDINIW | 200 但 0 行（无此代码）；实时接口确认腾讯美元指数代码为 `whUSDX`（99.02@2026-08-24），其历史日线未再深探（新浪已满足） |
| Stooq dx.f / usdidx | HTTP 200 但返回 JS 验证页（"This site requires JavaScript"），纯标准库无法过验 → 不可用 |
| 新浪 fx_sdiniw | ✅ **首选可用**：环球外汇美元指数日线，jsonp 大字符串（竖线分行，字段序 date,open,low,high,close 经逐行 OHLC 关系验证），实测 2000-01-03 ~ 2026-08-24 共 6,938 行（接口实际可回溯至 1985 年，为控制体量与既有库起点一致取 2000 起）。注意该接口有频率限制（HTTP 456），需节流 |

### 回补执行
- 选源：`sina fx_sdiniw`（现货美元指数、全史、字段关系自洽）
- 写入：`global_kline(market='fx', sym='DINIW')`，主键 (sym,date) `INSERT OR REPLACE`，
  过滤 `date<=今天`（不回补未来日期），单事务一次提交
- 校验：`SELECT COUNT(*), MIN(date), MAX(date) WHERE sym='DINIW'` →
  **6,939 行（2000-01-03 ~ 2026-08-24）**
- 哨兵复查：`global_kline` 检查项 thin=False，美元指数兜底恢复健康 ✅
