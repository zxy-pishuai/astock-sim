# Phase 9：新闻板块视图（利好利空聚合）

日期：2026-08-23 凌晨（周末休市）

## 1. 功能
- AI 提示词升级：每条新闻额外输出 sec 数组（关联板块名 + 方向 1=利好/-1=利空/0=中性，0-3 个）。
- 新接口 `/api/news/sectors`（sector_view）：新闻按板块聚合，输出
  {name, net, bull, bear, flat, count, news[]} 按 |net| 排序。
- 前竘新增「🏷️ 板块多空」视图：板块卡片（利好/利空/相关 徽章 + 净方向），
  点击展开看每条新闻的 ▲利好/▼利空 标注、AI 影响说明、时间来源；前 3 名默认展开。
- 列表视图每条新闻加板块色片（红=利好 绿=利空）。
- 资金流页关联板块提示行升级为「板块名(N利好/M利空)」。
- 无 AI 时降级：个股代码经 sector_map 反查 + 标题匹配行业名（dir=0 显示为「相关」）。
- 板块名归一化：去掉「行业/板块」后缀后聚合（如 家电行业=家电）。

## 2. 修复的两个关键 bug（AI 多空一直不出结果）
- **LLM 超时不足**：批量评分（30 条+板块输出）实测需 ~73s，原全局 90s 超时偶发打断。
  ai._chat 增加 timeout 参数，新闻批量任务用 240s。
- **AI 结果被重采清掉**：原始新闻 120s 就重采一次并重置 AI 缓存，而结果缓存 TTL 是 300s——
  AI 跑完时结果缓存还没过期，等缓存过期时原始数据早已重采，AI 分永远送不出来。
  重采窗口 120s→60 0s（盘前新闻无需高频重采；手动「刷新」仍强制重采）。
- 另加失败日志：AI 后台任务失败会在服务端日志打印原因，不再静默。

## 4. 注意
