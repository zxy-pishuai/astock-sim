# Phase 42：真打板回测引擎报告 —— 补上排板成交不确定性与炸板风险

- 时间: 2026-08-25
- 交付: `app/board_true.py`（新模块 TrueBoardBacktest）、`tools/backtest_true_board.py`、
  `data/bt_true_board.json`、本报告
- 窗口 = min5 覆盖期 2025-08-18~2026-08-21；池 = bt_pool 前 300（滤 DATA_EXCLUDE_CODES/ST）
- **结论先行: ① 日线近似对打板的"收益高估/低估"完全取决于排板成交假设——三档模型收益
  从 -10.6%（M1）到 +250.8%（M3），跨度 261pp；现有日线近似(+79.2%)落在中性假设 M2
  (+66.4%) 与激进上限之间。② 中性假设下打板仍为正期望（+66.4%，胜率 75%）；保守假设
  （封死单全部排队失败）下为负期望（-10.6%）。③ 炸板单次日平均 +0.88%、高开仅 +0.15%，
  显著弱于封死单的 +3.10%/+2.59% —— "炸板单应尽快处置"方向成立。**

## 1. 信号与成交模型（全部假设，无一隐藏）

| 环节 | 模型 |
|---|---|
| 触板 | min5 bar high ≥ 涨停价（`engine.limit_prices(昨收)` 口径；首根满足的 bar 时刻=排队时刻） |
| 封死/炸板 | 当日收盘==涨停价 → 封死；否则炸板 |
| M1 保守 | 仅炸板单成交（封死单视为排队失败）；成交价=涨停价 |
| M2 中性 | 炸板单 100% 成交；封死单按首触时间给概率：10:30 前 0.3 / 之后 0.6（seed=42 可复现） |
| M3 激进 | 全部触板单成交（上限对照） |
| 买入 | 涨停价×(1+0.001)；费用=engine.buy_fee/sell_fee 只读引用 |
| 组合 | 初始 10 万、MAX_POS=2、单仓=cash×25%、同日按首触时间先后入槽 |
| T+1 | 买入当日不可卖 |

## 2. 退出（日线执行，语义对齐 engine 参数）

阶梯止盈 [(+4%,卖33%),(+6%,卖33%)] → 止损 -5% → 全清止盈 +8% → 时间止损(3天且浮亏)
→ 超时 10 天；卖出=收盘×(1-滑点)。**未复刻**：冲高回落止盈、移动止损、主力出货检测
（任务书限定四项退出集；这三项会小幅改变结果，接入阶段需对齐）。

## 4. 三个判定问题的回答

### ① 日线近似高估/低估了多少？
- 相对保守口径 M1：日线近似 **高估约 90pp**（+79.2% vs -10.6%）；
- 相对中性口径 M2：高估约 13pp（+79.2% vs +66.4%）；
- 相对激进上限 M3：**低估 171pp**。
- M3−M1 差距 **261pp**：排板能否成交是打板策略最大的单一不确定性来源，
  任何不含成交模型的打板回测数字都不具备参考意义。

### ② 哪种成交假设下仍为正期望？
- M2（炸板全成、封死单 30%/60% 概率）：**+66.4%，正期望成立**，回撤 -13.7% 可接受；
- M1：负期望 —— 若封死板一律排队失败（只吃到炸板票），策略亏损；
- 盈亏平衡点介于两者之间，实际排队位置决定真实期望，接入前必须实测自身排单成交率。

### ③ 炸板单的最优处置
生态统计（1301 次触板，封死率 59.9% / 炸板率 40.1%；首触时间与封死率几乎无关：
10:30 前 58.7% vs 后 60.7%）：

| 触板结局 | 样本 | 次日平均涨幅 | 次日平均高开 | 次日上涨占比 |
|---|---|---|---|---|
| 封死 | 768 | **+3.10%** | +2.59% | 68.0% |
| 炸板 | 520 | +0.88% | **+0.15%** | 53.9% |

炸板票次日接近平开（+0.15%）且均值仅 +0.88% —— **"炸板单不应抱有次日溢价幻想，
应尽早处置"成立**；而封死票的高开垫（+2.59%）正是 M2/M3 正期望的主要来源。

## 5. 与 Phase26/30 结论的关系

- Phase26 承认的"日线近似"缺口在本模块补上；Phase30 归因发现的"涨停动量极强/很强
  有效、启动档拖累"在更真实的成交假设下依然成立方向（本阶段未重复归因，见 Phase41）。
- engine_minute 的 board_intraday（盘中 7~9.8% 未封买入）在同窗口为 **-17.9%**：
  其"bar 收盘买入"同样回避了排板问题，但买的是未封住的板，风险特征最差。

## 6. 局限声明

- 成交概率参数（0.3/0.6）为先验设定，非实测排队数据；M2 敏感性未扫描；
- 排队撮合简化为"炸板=必成交、封死=按时间概率"，未建模撤单打回、部分成交与排队位置漂移；
- 退出在日线收盘触发，未用 min5 精确盘中止损时点（会略偏乐观/悲观未知）；
- 幸存者偏差同前（bt_pool 为当前在市票）；min5 数据仍在被 updater 持续写入，
  本轮回测时点为 2026-08-25（覆盖期尾部数据可能再修订）。
