# K14｜机构一致预期 EPS → forward_pe 因子（研究型）

> 
> ## ★ 0. 预注册判据（先于任何评估固定；工具 `tools/k14_eps_collect.py` 文件头同文）
>
> - **F1 因子定义**：`PE_fwd = close_t / eps_consensus(next_uncompleted_year)`，
>   其中 `eps_consensus` = 同花顺一致预期 EPS **均值**（v2_mean）；`next_uncompleted_year` = 预测年度列表里 ≥ 当年且未出实际值的第一个年份；
>   信号用其**横截面倒数** `eps_yield_fwd = eps_consensus / close_t`（PE_fwd 的倒数，量纲稳）。
> - **F2 机构门**：`n_inst < 3` 的样本剔除（预测噪声）。
> - **F3 PIT 纪律（本轮最大约束的诚实声明）**：worth.html **只有现时点口径，无历史发布时间戳**——
>   不可做逐日历史回放。因此本因子采用**每日快照增量累积**（`data/vendor/k14/eps_snap_{yyyymmdd}.json`），
>   因子值锚定“快照日并仅用该日及以前的数据”；**绝不事后回填历史日期**。
> - **F4 样本判据**：累计 ≥ **20 个交易日**才允许第一次 fwd5 IC 初验；≥60 日为 provisional、
>   ≥120 日为 confirmed 分级。此前只输出 QC/覆盖统计，不做任何 alpha 判定。
> - **F5 判定**（20 日后触发）：横截面 Spearman IC（fwd5）月度聚合（同 `factor_ic_audit.py` 口径）——
>   月度 ICIR ≥ +0.3 且五分位多空单调 → “建议落地 `scoring.py`”；ICIR ≤ −0.3 → 反向同权；
>   其间区间 → exploreratory 不做结论。对照底座 = `factor_ic_audit`（18 K 线成分代理、fwd5 同定义）。
> - **F6 不落地红线**：所有结论**只出建议**；落地与否由用户拍板；不改 `app/config.py`。

## 2. 口径的三个坑（已在判据里钉死）

1. **无历史发布戳**：现时点 EPS 预测不能当“当年同日预测”用 → 本因子只能攒样本，不许回填历史（F3）。
2. **行业平均数**（v4）可能是全行业口径均值，不随每只票变化（300308/300502/688825 同行业实测 2.90/4.22 一致）→ 按**横截面行业指数（v2/v4 相对位）**用，而不是绝对值。
3. **覆盖度判定**：worth.html 对无预测票给空/薄样本（n_inst 小），K14 POC 统计剔除比例；低于 40% 覆盖则方案FAIL。
