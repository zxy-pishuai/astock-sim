# Phase 33：打板动量档位精调 —— 砍掉亏钱的"启动"档

- 时间: 2026-08-25
- 证据来源: Phase30 归因（data/attribution/by_signal.json）——启动档（昨日涨幅
  7~8%）334 回合净亏 −30,939 元、盈亏比 0.87；很强/极强档（8.5%+）合计 +35,672 元
- 结论先行: **判定通过，`BOARD_MOMENTUM_MIN` 默认由 7.0 改为 8.0**。
  网格三档全部满足事先判定规则，8.0 以平均 Δ+8.37pp 最优胜出；
  牛市窗口 +25.57pp，启动档触发清零。这是近期首个建议默认启用的正结果。

## 1. 实现（两处改动）

- `app/config.py`：新增 `BOARD_MOMENTUM_MIN = 8.0`（判定后默认值）
- `app/scoring.py` score_board 动量块：逐档显式门控
  `if pct >= 档位边界 and pct >= BOARD_MOMENTUM_MIN`——低于下限不给任何动量分，
  各档原始边界（9.0/8.5/8.0/7.0）不变；MIN=7.0 时与改动前行为逐位一致
  （合成用例回归验证：MIN∈{7.0,7.5,8.0,8.5} × pct∈{7.2,7.5,8.2,8.7,9.3} 全组合）

## 4. 判定（事先写死）

规则：某阈值 ≥3/4 窗口 Δ≥−1pp 且牛市窗口恶化 ≤2pp → 默认改为最优值
（达标者中平均 Δ 最高者）。

- 7.5 / 8.0 / 8.5 三档全部达标；平均 Δ 排序 8.0(+8.37) > 7.5(+6.13) > 8.5(+4.96)
- **采纳 MIN=8.0**

### 交易笔数变化与稳健性说明（规则要求）
- 采纳档 8.0 的笔数变化：W1 628→513（−18%）、W2 747→674（−10%）、
  W3 616→520（−16%）、W4 448→431（−4%）——减少的正是原启动档贡献的信号，
  与机制一致且幅度可解释。
- 诚实备注（不改变判定，供验收方参考）：按"每窗口都不恶化"的更严标准看，
  7.5 是唯一 4/4 改善或持平的档位（最差 −0.78pp），而 8.0 在 W1 有 −7.36pp
  的回撤端代价（但 W1 回撤仍从 −27.8% 收窄到 −23.4%，且换来其余三窗大幅改善）。
  规则事先锁定为"平均 Δ 最高"，故默认取 8.0；若验收方偏好无恶化变体，
  7.5 的证据同样成立。
