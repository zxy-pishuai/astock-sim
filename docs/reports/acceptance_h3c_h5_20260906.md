## §3 🔴 本班最大新发现：`amount` 字段系统性缺失（历史遗留，非今日引入）

全库扫描（`period='day'`，耗时 54.3s）：
```
日K 总行数                 8,745,871
volume>0 且 amount<=0      76,100 行  = 0.8701%
涉及去重代码数               753 个
按代码集中（前 8）    sz399006=600  sz399001=600  sh000001=600  510300=409
                     001337=400  001203=400  000963=399  000960=398
按日期的近期发生率     9/4=9   9/3=10   9/2=55   8/26=57
```
判读（保守）：
- `volume>0` 而 `amount=0` **在物理上不可能**，个股部分**必为坏数据**；
- 3 只指数（`sh000001/sz399001/sz399006`）与 1 只 ETF（510300）各约 400-600 根**整段缺失**，指数无成交额字段可能是源语义差异，需单独定性，**不计入个股缺陷**；
- 但 `001337/001203/000963/000960` 这类**个股整段历史约 400 根全为 0** → 是"某些代码取数链始终拿不到 amount"的结构性缺陷；
- 且**每天新增仍有 9-57 票**发生 → 不是纯历史问题，现在仍在产生。
- **潜在影响面**：凡以成交额为输入的因子（资金面 top30、量价背离、换手/成交结构类）会把这 750 只当"零成交"。
  这与我此前"核实撮合真实性/费率为强项"的判断不冲突，但**新增一条未登记的技术债**。
